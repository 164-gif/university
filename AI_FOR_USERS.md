# AI-помощник для University Notes

Этот раздел нужен пользователю, который хочет дать AI доступ к правилам и учебным материалам University Notes.

## Важно

Обычный браузерный чат не всегда умеет открыть GitHub Pages, raw-файлы и связанные URL. Поэтому способ с одной ссылкой работает не у всех моделей.

Если нужен **надёжный доступ ко всему репозиторию**, используйте AI, который:

- работает прямо в локальной папке после `git clone`;
- подключён к GitHub через connector/integration;
- или сам получает репозиторий в своей coding-agent среде.

Подробная таблица совместимости: [[AI_COMPATIBILITY|Какие AI подходят и как их подключить]].

## Что рекомендуется

Лучшие варианты для всего репозитория:

- **ChatGPT + GitHub connector**;
- **Qwen Code**;
- **OpenAI Codex**;
- **Claude Code**;
- **Gemini CLI**;
- **Cursor Agent**;
- **GitHub Copilot coding agent**.

Обычные **Gemini Chat**, **DeepSeek Chat**, **Qwen Chat** и другие браузерные чаты могут не открыть все связанные страницы, поэтому для них доступ через одну ссылку не гарантируется.

## Как работает вариант с одной ссылкой

1. Нажмите **«Копировать промпт»** ниже.
2. Отправьте скопированный текст нужному AI.
3. AI попробует открыть специальную plain-text инструкцию без JavaScript и клиентского рендеринга.
4. Если доступ разрешён, AI получает правила и карту материалов.
5. После успешного ознакомления AI должен ответить строкой с маркером `⟦UNIV-AI-READY⟧`.

Если AI пишет, что ссылка недоступна, это обычно ограничение его браузерного режима. В таком случае используйте один из рекомендуемых coding-agent вариантов выше.

## Промпт

> Прочитай полностью инструкцию University Notes по этой прямой текстовой ссылке, выполни указанный в ней порядок ознакомления и подготовься работать с материалами: https://164-gif.github.io/university/AI_ENTRY.txt

## Самый надёжный способ

Для Qwen Code, Claude Code, Gemini CLI, Codex, Cursor и других локальных агентов:

```bash
git clone https://github.com/164-gif/university.git
cd university
```

Затем запустите выбранного агента в этой папке и отправьте:

> Сначала прочитай `usethis.md`, `AGENTS.md` и `README.md`. Затем изучи структуру `subjects/` и связанные инструкции. Не выдумывай отсутствующие данные. При ответах на тесты сначала ищи подтверждённые ответы в `exam/`, затем материалы преподавателя в `notes/` и `transcripts/`.

После этого AI читает репозиторий напрямую через файловую систему, поэтому GitHub Pages ему уже не нужен.
