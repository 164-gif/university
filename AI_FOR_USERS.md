# Работа с AI

Этот раздел показывает, каким AI можно дать доступ к материалам University Notes и какой способ использовать.

## Сначала проверьте полный доступ

То, что AI смог открыть `AI_ENTRY.txt` и написал `⟦UNIV-AI-READY⟧`, **ещё не доказывает**, что он сможет потом открыть каждый конспект, тест или вложенный файл.

Для этого есть отдельная проверка: [[AI_TEST|Полный тест доступа AI]].

Тест заставляет AI открыть **каждый опубликованный текстовый материал**, прочитать уникальный контрольный фрагмент в конце каждого файла и собрать итоговый ключ. Если хотя бы часть URL недоступна, корректный ключ получить нельзя.

Используйте этот тест при первой проверке новой модели или после заметного обновления приложения AI.

## Обычные AI на телефоне

Эти варианты подходят для обычного приложения на Android без CLI, терминала и локального клонирования репозитория.

### Qwen

**Статус:** ⚠️ базовый доступ есть, но полный тест University Notes не пройден.

Qwen может открыть часть опубликованных материалов, однако текущая проверка не подтвердила доступ ко всем файлам. Поэтому Qwen пока не считается полностью совместимым с University Notes.

Нажмите кнопку **«Qwen — копировать промпт»**, откройте обычное приложение Qwen и отправьте скопированный текст в новый чат.

### Claude

**Статус:** ✅ подтверждённо читает опубликованные материалы University Notes в обычном приложении.

Claude успешно открывает короткие AI-ссылки вида `/ai/f/<id>.txt` и читает `TEST_FRAGMENT` из реальных файлов.

**Нюанс:** у Claude есть лимит на количество веб-страниц/URL, которые он может открыть за один ход. В нашей проверке он успел открыть **24 файла подряд из 132**, после чего остановился именно из-за лимита инструмента, а не из-за недоступности University Notes.

Поэтому для обычных вопросов по одному предмету или нескольким материалам Claude подходит нормально. А полный тест всего репозитория может потребовать несколько сообщений или продолжение с нужного номера файла.

Нажмите кнопку **«Claude — копировать промпт»**, откройте обычное приложение Claude и отправьте текст в новый чат.

### GLM / Z.ai

**Статус:** ✅ полная совместимость подтверждена.

GLM / Z.ai успешно прошёл **полный тест доступа University Notes**: смог открыть все файлы из теста и собрать корректный итоговый ключ.

Это сейчас самый сильный подтверждённый вариант для обычного использования с телефона через опубликованный сайт.

Нажмите кнопку **«GLM (Z.ai) — копировать промпт»**, откройте Z.ai и отправьте текст в новый чат.

### Общий промпт для этих AI

> Прочитай полностью инструкцию University Notes по этой прямой текстовой ссылке, выполни указанный в ней порядок ознакомления и подготовься работать с материалами: https://164-gif.github.io/university/AI_ENTRY.txt

После успешного ознакомления AI должен ответить:

`Готов. Ознакомился с правилами University Notes и картой материалов. ⟦UNIV-AI-READY⟧`

Это подтверждает только чтение входной инструкции. Для проверки реального доступа ко всем материалам используйте отдельный полный тест.

## ChatGPT

ChatGPT выделен отдельно, потому что доступ к самому GitHub Pages-сайту без дополнительных источников может быть недоступен в конкретном режиме приложения.

### Рекомендуемый вариант: отдельный проект + GitHub

Для постоянной работы с University Notes удобно создать отдельный проект в ChatGPT и использовать его только для университета.

В проекте:

1. Подключить GitHub к ChatGPT.
2. Указать репозиторий `164-gif/university`.
3. В первом сообщении попросить прочитать `usethis.md`, `AGENTS.md`, `README.md` и структуру `subjects/`.
4. Дальше все вопросы по университету задавать внутри этого проекта.

Стартовый запрос:

> Используй репозиторий `164-gif/university` как основной источник University Notes. Сначала прочитай `usethis.md`, `AGENTS.md`, `README.md`, затем изучи структуру `subjects/`. При ответах на тесты сначала проверяй подтверждённые ответы в `exam/`, затем материалы преподавателя в `notes/` и `transcripts/`. Не выдумывай отсутствующие данные.

### Нюансы ChatGPT

- без подключённого GitHub обычная ссылка на сайт может не открываться;
- с GitHub ChatGPT читает файлы репозитория напрямую;
- отдельный проект удобен тем, что все университетские чаты и контекст находятся в одном месте;
- если GitHub не подключён, для сайта сейчас лучше использовать GLM/Z.ai или Claude;
- тест сайта проверяет именно веб-доступ; GitHub-коннектор — отдельный способ доступа и его результат с веб-тестом смешивать не нужно.

## Агенты

Если нужен не только ответ по материалам, но и чтение всего репозитория, поиск по файлам, редактирование и работа с GitHub, используйте AI-агентов.

Подходят:

- **Qwen Code**;
- **OpenAI Codex**;
- **Claude Code**;
- **Gemini CLI**;
- **Cursor Agent**;
- **GitHub Copilot coding agent**.

Для локальных агентов:

```bash
git clone https://github.com/164-gif/university.git
cd university
```

После запуска агента:

> Сначала прочитай `usethis.md`, `AGENTS.md` и `README.md`. Затем изучи структуру `subjects/` и связанные инструкции. Не выдумывай отсутствующие данные. При ответах на тесты сначала ищи подтверждённые ответы в `exam/`, затем материалы преподавателя в `notes/` и `transcripts/`.

Подробности: [[AI_COMPATIBILITY|Полная совместимость AI]].

## Пока не поддерживают обычный способ через сайт

### Gemini

**Статус:** ❌ обычное приложение Gemini сейчас не проходит текущую схему доступа к University Notes.

Для Gemini можно использовать **Gemini CLI** на ПК как агента.

### DeepSeek

**Статус:** ❌ обычный DeepSeek Chat сейчас не подходит для схемы через сайт.

Он может прочитать входную страницу, а затем потерять доступ к связанным материалам. Именно для обнаружения такого ложноположительного результата и создан полный тест.

### Другие AI

Если приложение не проходит [[AI_TEST|полный тест доступа]], оно не должно помечаться как полностью поддерживаемое, даже если успешно прочитало главную инструкцию.
