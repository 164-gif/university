## Защита коммерческой тайны

В конспекте противопоставлены два подхода:
- для государственной тайны записано, что закон устанавливает, какие виды информации относятся к ней;
- для коммерческой тайны записано, что существует перечень информации, которую нельзя объявлять коммерческой тайной.

На странице перечислены примеры таких сведений:
1. данные из учредительных документов организации;
2. данные о регистрациях организации;
3. данные о численности сотрудников;
4. условия труда;
5. ещё один пункт о данных организации читается не полностью;
6. «и т. д.».

## Юридические и организационные меры

В тетради указано:

1. составить перечень информации, которую предприятие относит к коммерческой тайне;
2. разработать положение, в котором определяется порядок доступа, хранения и обращения с такой информацией;
3. ознакомить сотрудников с положением под роспись;
4. закрепить работу с коммерческой тайной в трудовых договорах;
5. прилагать отдельную подписку о неразглашении;
6. проводить обучение сотрудников по безопасности.

## Ограничение доступа

Записан принцип:

> Каждый сотрудник может работать только с той информацией, которая ему требуется для выполнения служебных обязанностей.

## Технические мероприятия

На странице перечислены:
- ограничение прав доступа;
- программные решения;
- следующий пункт в исходнике не заполнен либо не читается.

## Учёт и контроль

В конспекте записано:
- документы передаются под роспись;
- учитывается количество экземпляров;
- для электронного хранения/обработки упоминается шифрование;
- **AES** записан как пример шифрования.

## Ответственность за нарушения

Перечислены:
1. дисциплинарная — замечание, выговор, понижение/увольнение (часть формулировки читается не идеально);
2. материальная ответственность;
3. административная;
4. уголовная — в записи указана **ст. 183**.
