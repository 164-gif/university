# There might be a mistake

Здесь фиксируются возможные ошибки, неточности, устаревшие сведения и сомнительные места в конспекте по предмету **«Введение в информационную безопасность»**.

> [!important]
> Найденное расхождение не означает автоматическое исправление основного конспекта. Исходная запись сохраняется, а проверка документируется отдельно.

## Формат записи

- **Файл:**
- **Место:**
- **Исходный фрагмент:**
- **Тип проблемы:**
- **Почему вызывает сомнение:**
- **Что, вероятно, нужно исправить:**
- **Уровень уверенности:** низкий / средний / высокий
- **Источник проверки:**
- **Дата обращения к источнику:**
- **Статус:** не проверено пользователем

---

Пока файл содержит только шаблон. Новые замечания добавляются по мере фактической проверки материала.
