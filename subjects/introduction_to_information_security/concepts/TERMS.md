# Термины из конспекта

- **Информация как объект защиты** — в записи подчёркнута её нематериальность и связь защиты с материальным носителем.
- **Конфиденциальность** — одно из перечисленных в тетради свойств информации.
- **Организационно-правовая защита** — одно из направлений защиты информации.
- **Инженерно-техническая защита** — одно из направлений защиты информации.
- **Программно-аппаратная защита** — одно из направлений защиты информации.
- **Криптографическая защита** — одно из направлений защиты информации.
- **Государственная тайна** — отдельный раздел правовой защиты в конспекте.
- **Коммерческая тайна** — отдельный раздел, для которого рассматриваются перечень сведений, положение и разграничение доступа.
- **Режимное предприятие** — в тетради: предприятие, работающее с государственной тайной.
- **AES** — в записи приведён как пример шифрования.
