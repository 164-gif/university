# Предметы

Для каждого предмета создаётся отдельный профиль и отдельная структура.

```
subjects/<subject>/
├── README.md
├── raw/
├── transcripts/
├── notes/
├── summaries/
├── concepts/
└── exam/
```

## README предмета

Должен фиксировать:
- полное название предмета;
- преподавателя, если это нужно для контекста;
- особенности терминологии;
- требования к оформлению;
- формат зачёта/экзамена, если он известен;
- известные источники и учебники;
- отличия от общих правил.

Общие требования одного предмета нельзя автоматически переносить на другой.

Исходные файлы не перезаписывать. Все производные версии хранить отдельно.
