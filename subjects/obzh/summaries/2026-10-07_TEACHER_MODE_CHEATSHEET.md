# ОБЖ 07.10 — шпаргалка именно под преподавателя

> [!important]
> Теперь известны все пять вариантов. Нумерация: старые фото — **1, 4, 5**, новые — **2, 3**. Формулировки здесь ориентированы на тест преподавателя, а не на внешний fact-check.

## Выучить без раздумий

- Первая помощь начинается с **обеспечения безопасности**.
- Помощь лицами без медобразования = **первая помощь**.
- Признаки жизни: **сознание + дыхание**.
- Осмотр: **голова → шея → грудная клетка → живот/таз → конечности**.
- Рана = нарушение целостности кожи/слизистой с возможным повреждением глубжележащих тканей и органов.
- Свежая рана: **боль + зияние + кровотечение**.
- Кровотечение = выход крови из сосудистого русла во внешнюю среду или ткани/полости организма.
- Артериальное: **ярко-алая кровь + пульсирующий/быстрый ток**.
- Венозное: **тёмно-вишнёвая кровь + непульсирующий ток**.
- Капиллярное: **поверхностное повреждение + непульсирующий ток + капли «как из губки»**.
- Острая кровопотеря: **бледность + низкое АД + частый нитевидный пульс**.
- Временная остановка: **прямое давление → давящая повязка → жгут**.
- Правильный жгут: **кровотечение прекратилось + кожа побледнела**.
- По тесту: жгут **до 2 часов**.
- Носовое кровотечение: **голова вперёд → прижать крылья → холод → при необходимости марлевая турунда**.
- Инородный предмет из раны **не извлекать**.
- 112 = единый номер экстренных служб.
