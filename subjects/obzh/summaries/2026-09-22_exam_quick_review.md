# 22.09 — быстрое повторение перед опросом

> [!warning] Статус
> Это краткая выжимка по лекции, а не отдельная медицинская инструкция. Проверенные расхождения с актуальными материалами см. в [[../checks/There might be a mistake]].

## Сверхкраткий список

1. Ошибки и правила наложения жгута; время и отметка времени по лекции.
2. Носовое кровотечение: голова вперёд, крылья носа, холод.
3. Определение травмы; множественные / сочетанные / комбинированные повреждения.
4. Перелом: определение; абсолютные и относительные признаки.
5. Транспортная иммобилизация: определение + правило двух суставов.
6. Первая помощь при закрытом и открытом переломе.
7. Травма позвоночника: ключевые признаки и минимизация перемещений.
8. Перелом таза: симптом пятки + поза лягушки.
9. Сдавление мозга: светлый промежуток + анизокория.
10. Перелом основания черепа: кровь из носа/ушей + травматические очки.
11. Гемоторакс / пневмоторакс; помощь при проникающей ране груди.
12. Острый живот: определение, симптомы, запреты.
13. Терминальное состояние: 3 фазы; определение клинической смерти.
14. СЛР взрослому: C–A–B; 10 сек; 5–6 см; 100–120/мин; 30:2.
15. СЛР детям/при утоплении: 5 начальных вдохов (по лекции).
16. Инородное тело: 5 ударов по спине + 5 приёмов Геймлиха; особенности беременных/тучных.
17. Эпидемиология: определение; эпидемический процесс; 3 звена цепочки; источник инфекции.

## Блоки «ВЫУЧИТЬ»

### ВЫУЧИТЬ
- Техника туров: перекрытие примерно на 1/2 предыдущего тура.
- Обязательно: время наложения + давящая повязка на рану.
- По лекции: максимальное время — 2 часа; при повторном наложении фиксируют новое время.
- Импровизированный жгут: ширина не менее 2,5 см.

### ВЫУЧИТЬ
- Жгут вокруг шеи без опоры не накладывают.
- При открытой ране шеи — закрыть рану, чтобы ограничить попадание воздуха.

### ВЫУЧИТЬ
- При венозном кровотечении жгут в лекции назван ошибкой.
- Правильно наложенный жгут: кровотечение прекращается, конечность бледнеет, ниже места наложения пульс не определяется.

### ВЫУЧИТЬ
- Голову — вперёд, не назад.
- Прижать крылья носа + холод.

### ВЫУЧИТЬ
- Определение травмы.
- Разница: множественные / сочетанные / комбинированные повреждения.
- Порядок первичного осмотра.

### ВЫУЧИТЬ — ОДИН ИЗ ГЛАВНЫХ ВОПРОСОВ
- Абсолютные признаки перелома — перечислить все.
- Относительные признаки: боль, отёк, нарушение функции.
- По лекции наличие хотя бы одного абсолютного признака позволяет уверенно говорить о переломе.

### ВЫУЧИТЬ
- Определение транспортной иммобилизации.
- Правило двух суставов.
- Алгоритм при закрытом и открытом переломе.

### ВЫУЧИТЬ
- При переломе бедра — три шины и их направление.

### ВЫУЧИТЬ
- Два главных признака по лекции: резкая локальная боль + ограничение подвижности.
- При подозрении на травму позвоночника — минимум лишних перемещений.
- Шею фиксировать; извлечение из машины — только при необходимости/угрозе.

### ВЫУЧИТЬ
- Симптом пятки.
- Поза лягушки и фиксация ног при транспортировке.

### ВЫУЧИТЬ
- Определение ретроградной амнезии.
- Основные признаки сотрясения и 3 степени по длительности потери сознания (как в лекции).

### ВЫУЧИТЬ
- «Светлый промежуток» при сдавлении мозга.
- Анизокория (разная величина зрачков) как характерный признак по лекции.

### ВЫУЧИТЬ
- Кровь из носа/ушей после травмы + «травматические очки» — признаки перелома основания черепа по лекции.
- Ранящий предмет из головы не извлекать; фиксировать.

### ВЫУЧИТЬ
- При травме грудной клетки — сидя/полусидя (по лекции).
- Признаки перелома рёбер и подкожной эмфиземы.

### ВЫУЧИТЬ
- Гемоторакс vs пневмоторакс.
- Характерный признак проникающей раны: сасывающий звук + пузырение крови.
- Инородный предмет не извлекать; проникающую рану герметизировать.

### ВЫУЧИТЬ
- Определение «острого живота».
- Ключевые симптомы.
- Что нельзя делать: пить/есть, обезболивание, тепло на живот.

### ВЫУЧИТЬ
- Определение терминального состояния.
- Три фазы: преагония → агония → клиническая смерть.
- Определение клинической смерти.

### ВЫУЧИТЬ — КЛЮЧЕВОЙ АЛГОРИТМ
- C–A–B.
- Проверка дыхания — до 10 секунд.
- Компрессии взрослому: 5–6 см, 100–120/мин.
- Соотношение 30:2.
- Паузы между циклами — не более 10 секунд.

### ВЫУЧИТЬ
- Критерии эффективности СЛР.
- Основные технические ошибки СЛР.
- После восстановления жизненных функций — продолжать наблюдение.

### ВЫУЧИТЬ
- Дети и утопление: сначала 5 вдохов.
- Глубина компрессий: ~4 см до года, до 5 см у старших детей.
- Соотношение 30:2 по лекции.

### ВЫУЧИТЬ
- Взрослый: 5 ударов между лопатками → 5 приёмов Геймлиха → повторять.
- Беременные/тучные: не давить на живот, использовать грудные толчки.
- Потеря сознания → СЛР.

### ВЫУЧИТЬ
- Определение эпидемиологии.
- Определение эпидемического процесса.
- 3 звена эпидемиологической цепочки.
- Определение источника инфекции и кто им может быть.
