## Как пользоваться в Obsidian

1. Для обычного изучения открывать Markdown-файлы из `notes/`.
2. Перед тестом — `summaries/` и `exam/`.
3. Для повторения определений — `concepts/`.
4. Если формулировка выглядит спорной или медицински/нормативно устаревшей — смотреть `checks/There might be a mistake.md`.
5. Формулировки «по лекции» сохраняются даже при наличии замечания в `checks/`.

## Правила предмета

- Не смешивать разные лекции так, будто это одна запись.
- Не исправлять слова преподавателя молча.
- Медицинскую и нормативную проверку вести отдельным слоем.
- Если в исходнике есть схема — переносить её; если схема сильно помогает пониманию, допустима достоверная дополнительная иллюстрация с явной подписью.
- Для новых конспектов допустимы Mermaid-схемы, если они воспроизводят только подтверждённую структуру материала и не добавляют неподтверждённые факты.
