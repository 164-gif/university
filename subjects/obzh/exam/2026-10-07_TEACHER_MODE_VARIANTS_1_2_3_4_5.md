# Ключи и разбор

## Вариант 1

1. Состояния для первой помощи — **а, в, г, д**.
2. Первая помощь начинается с — **а) обеспечения безопасности**.
3. В универсальный алгоритм входят — **б, д**: обзорный осмотр на кровотечение; оптимальное положение тела.
4. Причины потери сознания — **а, д**: ЧМТ; отравление алкоголем.
5. Свежая рана — **б, в**: зияние; боль.
6. Определение — **кровотечение**.
7. Капиллярное кровотечение — **а, г, д**: поверхностное повреждение; ток не пульсирует; кровь каплями «как из губки».
8. Жгут — **5 → 3 → 2 → 4 → 1**.
9. Острая кровопотеря — **в)** бледность + низкое АД + частый нитевидный пульс.
10. Носовое кровотечение — **б, в, г**: голова вперёд; холод; марлевые турунды.

## Вариант 2

1. Определение — **первая помощь**.
2. Извлечение из труднодоступного места — по логике преподавателя **б)** только при угрозе жизни пострадавшего. Если речь идёт об экстренном извлечении для проведения СЛР, возможна трактовка **г)**, поэтому этот вопрос отмечен как требующий сверки с преподавательской формулировкой.
3. Порядок осмотра — **д)** голова → шея → грудная клетка → живот и таз → конечности.
4. Внутреннее кровотечение — ожидаемо **а, в, г**: холод; уложить; срочно вызвать/доставить в медучреждение. Обезболивающее не давать.
5. Свежая рана — **б, д**: кровотечение; зияние.
6. Артериальное кровотечение — **а, в**: ярко-алая кровь; пульсирующий ток.
7. Временная остановка кровотечения — **б, г, д**: прямое давление; давящая повязка; жгут.
8. Жгут нельзя накладывать — **б, в**: на обнажённое тело; ниже раны. Пункт про максимально близко к туловищу зависит от контекста повреждения и в качестве общего правила не выбирать.
9. Правильный жгут — **а, г**: побледнение; прекращение кровотечения.
10. При инородном предмете запрещается — **г)** извлекать предмет.

## Вариант 3

1. Состояния для первой помощи — **а, в, г, д**.
2. Признаки жизни — **б, в**: сознание; дыхание.
3. При первой помощи запрещается — **а, б**: давать лекарства без назначения; перемещать пострадавшего с потенциально тяжёлыми травмами без необходимости.
4. Раны по происхождению — по учебной классификации из предложенного набора наиболее вероятно **б, в**: случайные; операционные. Пункты «бытовые/производственные/сельскохозяйственные» относятся скорее к обстоятельствам получения травмы, поэтому этот вопрос отмечен как один из менее однозначных.
5. Кровь в ткани/органы/полости — **б) внутреннее кровотечение**.
6. Виды кровотечений — **б, в**: артериальное; венозное.
7. Венозное кровотечение — **а, г**: тёмно-вишнёвая кровь; течёт «ручьём» без пульсации.
8. Временная остановка — **б, в, д**: давящая повязка; жгут; прямое давление.
9. Жгут накладывают — **в)** выше раны на 5–7 см.
10. Экстренное извлечение при ДТП — **б)** есть угроза жизни/здоровью и невозможно оказать помощь в автомобиле.

## Вариант 4

1. Лицами без медобразования оказывается — **б) первая помощь**.
2. Не входит в универсальный алгоритм — **в) реакция зрачков на свет**.
3. Первая помощь начинается с — **д) обеспечения безопасности**.
4. Определение — **рана**.
5. Интенсивное наружное кровотечение — **а, б, д**: пропитанная кровью одежда; много крови рядом; интенсивно кровоточащая рана.
6. Виды кровотечений — **а, г, д**: наружное; внутреннее; капиллярное.
7. Артериальное кровотечение — **а, б, в**: быстро расплывающаяся кровь; струя; ярко-алая кровь.
8. Жгут-закрутка — **а, г**: галстук; ремень ≥2,5 см.
9. Правильный жгут — **а, г**: побледнение; прекращение кровотечения.
10. Последовательность — наиболее вероятно **4 → 3 → 5 → 2 → 1**. Этот пункт менее однозначен, потому что вызов 112/103 в конспекте стоит очень рано.

## Вариант 5

1. Определение — **в) первая помощь**.
2. Запрещается — **б, г**: давать обезболивающее; оставлять бессознательного дышащего на спине.
3. Признаки жизни — **а, в**: сознание; дыхание.
4. Осмотр — **а)** голова → шея → грудная клетка → живот/таз → конечности.
5. Паренхиматозное кровотечение — **в, г**: печень; селезёнка.
6. Острая кровопотеря — **в)** бледность + снижение АД + нитевидный пульс.
7. Венозное — **б, г**: вишнёвая кровь; непульсирующий ток.
8. Срок жгута — **г) 2,0 часа**.
9. Носовое кровотечение — **г → б → в → а**.
10. Единый номер — **112**.

# Что показывает полный набор из 5 вариантов

Теперь прогноз больше не нужен: известны все пять вариантов. Самые повторяемые темы:

- начало первой помощи с безопасности;
- понятие первой помощи;
- признаки жизни;
- порядок осмотра;
- определение раны и признаки свежей раны;
- определение кровотечения;
- артериальное, венозное, капиллярное, внутреннее кровотечение;
- признаки острой кровопотери;
- способы временной остановки кровотечения;
- наложение жгута, признаки правильности и срок;
- носовое кровотечение;
- инородный предмет в ране;
- экстренное извлечение пострадавшего.

## Приоритет подготовки

### A — повторяется в нескольких вариантах

1. Безопасность как первый этап.
2. Сознание + дыхание как признаки жизни.
3. Осмотр: голова → шея → грудная клетка → живот/таз → конечности.
4. Артериальное = алая + пульсирует.
5. Венозное = тёмно-вишнёвая + не пульсирует.
6. Капиллярное = капли/«как из губки».
7. Острая кровопотеря = бледность + низкое АД + нитевидный пульс.
8. Прямое давление → давящая повязка → жгут.
9. Правильный жгут = прекращение кровотечения + побледнение.
10. По тесту преподавателя жгут — до 2 часов.

### B — один-два варианта

- внутреннее и паренхиматозное кровотечение;
- инородное тело в ране;
- экстренное извлечение;
- классификация ран по происхождению;
- носовое кровотечение;
- причины потери сознания.

> [!warning]
> Вопросы 2.2, 2.4, 3.4 и 4.10 отмечены как менее однозначные. Если преподаватель даст официальный ключ, нужно заменить предположение на подтверждённый ответ, не удаляя исходную формулировку вопроса.
