# Мировоззрение и ценности

Лосев — духовная культура; Шрейбер — онтология, гносеология, аксиология; Апостель — гармония убеждений. Дильтей: знания — оценки — действия. Ценности по времени: вечные, мегаисторические, эпохальные, поколенческие, конъюнктурные; по пространству: универсальные, национальные, локально-групповые, индивидуальные. Соборность, солидарность, коммунитарность, всеединство, здоровый консерватизм. Пентабазис: человек — семья — общество — государство — страна.
