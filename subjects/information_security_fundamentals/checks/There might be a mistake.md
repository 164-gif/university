# There might be a mistake — Основы информационной безопасности

Дата проверки: **05.10.2026**.

> [!warning]
> Основные конспекты сохраняют содержание презентаций преподавателя. Ниже перечислены только места, где внешняя проверка выявила возможное расхождение или важную оговорку.

## 1. «HTML — основа современного Интернета» и «17 мая 1991 — дата рождения Интернета»

**Где:** `Л_1_основы ИБ.ppt`, исторический блок об Интернете.

**Формулировка презентации:** HTML назван основой современного Интернета; 17.05.1991 указано как дата утверждения WWW и «дата рождения Интернета в привычном понимании».

**There might be a mistake:** формулировка смешивает **Интернет** и **World Wide Web**. CERN указывает, что Тим Бернерс-Ли изобрёл Web в 1989 году, к концу 1990 года работали первый Web-сервер и браузер, а в августе 1991 года WWW был объявлен в интернет-группах новостей. 30.04.1993 CERN сделал программное обеспечение Web общедоступным. Отдельное утверждение о 17.05.1991 как общепринятой «дате рождения Интернета» официальной историей CERN не подтверждается.

**Что, вероятно, нужно исправить:** для точной формулировки различать Интернет как сетевую инфраструктуру и WWW как сервис поверх Интернета. Дату 17.05.1991 учить только как **формулировку презентации**, если преподаватель спрашивает именно по своим слайдам.

**Уверенность:** высокая.

**Источники:**
- CERN — *The birth of the Web*: https://home.cern/science/computing/the-birth-of-the-web/
- CERN — *A short history of the Web*: https://home.cern/science/computing/the-birth-of-the-web/short-history-web/
- **Дата обращения:** 05.10.2026.

## 2. «13 корневых серверов: 10 в США и по одному в Японии, Швеции и Нидерландах»

**Где:** `Л_2_основы ИБ.ppt`, раздел об инфраструктуре и стандартизации Интернета.

**Исходная формулировка:** 13 корневых серверов управления Интернетом, 10 из них в США и по одному в Японии, Швеции и Нидерландах.

**There might be a mistake:** современная DNS Root Server System действительно имеет **13 идентификаторов корневых серверов (A–M)**, но это не 13 физических машин. На дату проверки Root Server Technical Operations Association показывает **2045 операционных экземпляров**, которыми управляют 12 независимых операторов по всему миру.

**Что, вероятно, нужно исправить:** говорить «13 идентификаторов корневых серверов», а не «13 физических серверов». Географическое распределение из презентации нельзя применять к современной системе.

**Уверенность:** высокая.

**Источники:**
- Root Server Technical Operations Association: https://root-servers.org/
- FAQ Root Server System: https://root-servers.org/faq/
- **Дата обращения:** 05.10.2026.
