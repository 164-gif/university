# Лабораторные по физике

Отдельный предмет для лабораторных работ по физике. Здесь хранятся методички, условия, экспериментальные данные, несколько вариантов решений, вопросы к защите, графики и исходники.

## Правило структуры

Каждая лабораторная работа хранится **в своей отдельной папке**. Внутри могут быть:

- условие и цель;
- экспериментальные данные;
- одно или несколько решений;
- вопросы преподавателя;
- ответы для защиты;
- графики;
- исходные фотографии и методички.

Старые варианты решений не перезаписываются — новые добавляются отдельными файлами.
