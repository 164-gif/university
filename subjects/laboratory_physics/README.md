# Лабораторные по физике

Отдельный предмет для лабораторных работ по физике. Здесь хранятся методички, условия, экспериментальные данные, несколько вариантов решений, вопросы к защите, графики и исходники.

## Правило структуры

Каждая лабораторная работа хранится **в своей отдельной папке**. Внутри могут быть:

- `00 - Методичка.md` — привязка к исходной методичке и нужным страницам;
- условие и цель;
- экспериментальные данные;
- одно или несколько решений;
- вопросы преподавателя;
- ответы для защиты;
- графики;
- исходные фотографии.

Старые варианты решений не перезаписываются — новые добавляются отдельными файлами.

## Важные расхождения нумерации

> [!warning]
> В источниках есть расхождения, поэтому они **не исправлены автоматически**:
>
> 1. Статистическая работа в методичке и сообщении преподавателя обозначена как **№15**, а в тетради — как **№16**.
> 2. Под номером **№4** преподаватель присылал две разные работы: математический маятник и определение скорости звука.

## Общие требования преподавателя

По сообщению от 23.09.2026 и «Измерительному практикуму»:

- оформление чистовика — стр. 54–55;
- графическое представление результатов — стр. 47–48;
- пример расчета погрешностей прямых измерений — около стр. 38–39;
- для работ можно использовать цветные методички и «Измерительный практикум»;
- цветные методички желательно фотографировать.
