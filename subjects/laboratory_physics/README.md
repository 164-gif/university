# Лабораторные по физике

Отдельный предмет для лабораторных работ по физике. Здесь хранятся методички, условия, экспериментальные данные, несколько вариантов решений, вопросы к защите, графики и исходники.

## Правило структуры

Каждая лабораторная работа хранится **в своей отдельной папке**:

```text
laboratory_physics/
├── lab_16/
│   ├── README.md
│   ├── 01 - Условие и цель.md
│   ├── 02 - Экспериментальные данные.md
│   ├── 03 - Решение 1.md
│   ├── 04 - Контрольные вопросы.md
│   ├── solutions/
│   ├── graphs/
│   └── raw/
└── lab_XX/
    └── ...
```

Для одной лабораторной можно хранить несколько решений, вариантов расчётов и отчётов. Старые варианты не перезаписываются, а добавляются отдельными файлами.
