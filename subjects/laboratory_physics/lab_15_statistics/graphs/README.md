# Графики лабораторной №16

## Что должно храниться здесь

1. Исходный экспериментальный график из тетради.
2. Чистовой перерисованный график для $N=300$.
3. При необходимости — отдельные графики для $N=50$ и $N=150$.

На чистовом графике должны быть:

- ось $x$: номер ячейки $k$;
- ось $y$: частота $F_k$;
- экспериментальная гистограмма;
- экспериментальная плавная кривая;
- теоретическая кривая нормального распределения;
- легенда.

> [!warning]
> Чистовая картинка пока не создана, потому что генерацию/перерисовку отложили. После создания её нужно положить сюда отдельным изображением, а не встраивать как скрин страницы тетради.
