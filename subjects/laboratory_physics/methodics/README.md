# Методички по лабораторным работам

Каталог источников для лабораторных работ по физике.

## Загруженные методички

### `15 (2).pdf`

**Лабораторная работа №15 — «Ознакомление со статистическими закономерностями на механических моделях».**

- 6 страниц;
- теория случайных величин и статистических законов;
- нормальное распределение (Гаусс);
- распределение Максвелла;
- практическая часть с доской Гальтона;
- формулы теоретического распределения;
- контрольные вопросы.

Используется в `../lab_15_statistics/` и для сверки материалов `../lab_16/`.

### `Измерительный практикум (2).pdf`

А.А. Бирюков и др. **«Измерительный практикум. Механика»**, Самара, 2009.

Нужные разделы:

- обработка и оформление результатов — стр. 18–55;
- графическое представление результатов — стр. 47–48;
- требования к оформлению лабораторных — стр. 54–55;
- №2 «Изучение нониусов» — стр. 66–72;
- №3 «Определение плотности твердых тел пикнометром и гидростатическим взвешиванием» — стр. 73–78;
- №4 «Измерение промежутков времени» — стр. 79–85; по сообщению преподавателя для нашей работы требуется упражнение 1, стр. 82–83;
- №6 «Изучение законов прямолинейного равноускоренного движения на машине Атвуда» — стр. 93–105.

### `Biryukov_A_A_Dvizhenie_tverdogo_tela_2006 (1).pdf`

А.А. Бирюков, Э.Н. Воробьева, Б.В. Данилюк, Г.П. Мартынова. **«Движение твердого тела. Лабораторный практикум по общей физике. Механика»**, Самара, 2006.

Содержит десять лабораторных по динамике твердого тела. Для текущего курса особенно важна:

- Д-1 «Определение момента инерции твердого тела с помощью трифилярного подвеса» — стр. 25–32.

### `07 (1).pdf`

**Лабораторная работа №7 — «Определение коэффициента внутреннего трения вязкой жидкости по методу Стокса».**

Содержит теорию вязкости, закон Стокса, установку, порядок эксперимента, таблицы обработки и контрольные вопросы.

### `09 (1).pdf`

**Лабораторная работа №9 — «Длина свободного пробега».**

Содержит молекулярно-кинетическую теорию, явления переноса, теплопроводность, диффузию, внутреннее трение, описание установки, обработку результатов и расчет длины свободного пробега.

## Правило использования

1. Формулы и порядок выполнения брать прежде всего из соответствующей методички.
2. Вопросы преподавателя из `../teacher_messages/` имеют приоритет при подготовке к защите.
3. Если нумерация преподавателя, тетради и методички расходится, сохранять все варианты и явно указывать источник номера.
4. Не исправлять методичку по общим знаниям без отдельной проверки.
