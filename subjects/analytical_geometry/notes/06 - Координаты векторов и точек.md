# 06 — Координаты векторов и точек

## Базис

В пространстве используется базис:

[
\vec i,\;\vec j,\;\vec k
]

Вектор можно представить через координаты:

[
\vec a=(a_x,a_y,a_z)
]

## Длина вектора

[
|\vec a|=\sqrt{a_x^2+a_y^2+a_z^2}
]

## Скалярное произведение в координатах

Для
[
\vec a=(a_x,a_y,a_z),\qquad
\vec b=(b_x,b_y,b_z)
]

[
\vec a\cdot\vec b=a_xb_x+a_yb_y+a_zb_z
]

## Перпендикулярность

[
a_xb_x+a_yb_y+a_zb_z=0
]

## Коллинеарность

Координаты коллинеарных векторов пропорциональны.

## Направляющие косинусы

Направление вектора можно характеризовать косинусами углов с координатными осями.

## Радиус-вектор точки

Для точки (M(x,y,z)) её радиус-вектор имеет координаты:

[
\overrightarrow{OM}=(x,y,z)
]

## Вектор между двумя точками

Если
[
A(x_1,y_1,z_1),\quad B(x_2,y_2,z_2),
]

то

[
\overrightarrow{AB}=(x_2-x_1,\;y_2-y_1,\;z_2-z_1)
]

## Расстояние между точками

[
AB=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}
]
