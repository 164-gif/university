# Проверка материалов по кривым второго порядка

Дата проверки: 18.10.2026.

Проверены темы 11–14 и файл подготовки к тесту 19.10.2026.

## Подтверждено

Корректны:

- окружность $(x-a)^2+(y-b)^2=R^2$;
- эллипс $x^2/a^2+y^2/b^2=1$;
- связь для эллипса $c^2=a^2-b^2$;
- гипербола $x^2/a^2-y^2/b^2=1$;
- связь для гиперболы $c^2=a^2+b^2$;
- эксцентриситет $\varepsilon=c/a$;
- $0<\varepsilon<1$ для неокружностного эллипса, $\varepsilon=1$ для параболы, $\varepsilon>1$ для гиперболы;
- директрисы горизонтального эллипса и гиперболы $x=\pm a/\varepsilon=\pm a^2/c$;
- асимптоты горизонтальной гиперболы $y=\pm(b/a)x$;
- определение параболы через фокус и директрису;
- при принятом обозначении $y^2=2px$: фокус $F(p/2,0)$ и директриса $x=-p/2$;
- фокусно-директрисное свойство $MF/d=\varepsilon$;
- касательные к эллипсу и гиперболе;
- общее уравнение $Ax^2+2Bxy+Cy^2+2Dx+2Ey+F=0$;
- классификационная величина $\delta=AC-B^2$.

## Исправлено после проверки

В первоначальной версии темы 14 и подготовки было слишком сильное утверждение, что параллельным переносом всегда можно убрать все линейные члены.

Это верно для центральных коник при невырожденной квадратичной части, но **не является универсальным правилом для параболического случая**. Для параболы после приведения обычно остаётся один линейный член.

Материалы исправлены. Универсально безопасная схема теперь записана так:

1. при наличии $xy$ выполнить поворот осей;
2. выполнить перенос начала координат;
3. привести уравнение к каноническому виду;
4. учесть возможность вырожденного случая.

Также уточнено, что знак $\delta$ определяет тип квадратичной части, но сам по себе не гарантирует конкретную невырожденную кривую.

## Итог

После внесённых исправлений основные формулы и определения в блоке подготовки соответствуют стандартной аналитической геометрии и согласованы между темами 11–14.
