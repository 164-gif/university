Структура контрольной:

## Задание 1. Векторная алгебра

### База

Для точек `A(x1,y1,z1)` и `B(x2,y2,z2)`:

`AB = (x2-x1, y2-y1, z2-z1)`.

Длина вектора `a=(x,y,z)`:

`|a| = sqrt(x^2+y^2+z^2)`.

Скалярное произведение:

`a·b = ax*bx + ay*by + az*bz`.

Перпендикулярность:

`a·b = 0`.

Угол:

`cos φ = (a·b)/(|a||b|)`.

Векторное произведение:

`a×b = (ay*bz-az*by, az*bx-ax*bz, ax*by-ay*bx)`.

Площадь треугольника:

`S_ABC = 1/2 |AB×AC|`.

Смешанное произведение:

`(a,b,c) = det(a,b,c) = (a×b)·c`.

Компланарность:

`(a,b,c)=0`.

Объём тетраэдра:

`V = 1/6 |(AB,AC,AD)|`.

Высота треугольника из B на AC:

`h = |AB×AC|/|AC|`.

Высота тетраэдра из D на ABC:

`h = |(AB,AC,AD)| / |AB×AC|`.

### Наиболее вероятные типы по ДЗ

- №851 — вычисление векторного произведения и действия с векторами.
- №858 — высота треугольника через площадь/векторное произведение.
- №861 — нахождение неизвестного вектора по условиям перпендикулярности и длине.
- №866 — смешанное произведение взаимно перпендикулярных векторов.
- №877 — высота тетраэдра.
- №878 — объём тетраэдра и неизвестная вершина.

### Короткие алгоритмы

#### Векторное произведение

1. Найти нужные векторы по координатам точек.
2. Подставить их в формулу `a×b`.
3. Проверить знак и порядок: `a×b = -(b×a)`.

#### Площадь треугольника

1. Найти `AB` и `AC`.
2. Найти `AB×AC`.
3. Найти его длину.
4. Разделить на 2.

#### Смешанное произведение / объём

1. Найти три вектора из одной вершины.
2. Вычислить определитель 3×3.
3. Для объёма взять модуль и разделить на 6.

#### Компланарность

Вычислить `det(a,b,c)`. Если он равен нулю, векторы компланарны.

#### Неизвестный вектор

Пусть `m=(x,y,z)`.

- `m ⟂ (a,b,c)` → `ax+by+cz=0`.
- `|m|=L` → `x^2+y^2+z^2=L^2`.
- `m ⟂ Ox` → `x=0`.
- `m ⟂ Oy` → `y=0`.
- `m ⟂ Oz` → `z=0`.
- острый угол с `Ox` → `x>0`.

## Задание 2. Прямая на плоскости

### База

Общее уравнение прямой:

`Ax + By + C = 0`.

Нормальный вектор:

`n = (A,B)`.

Направляющий вектор:

`s = (-B,A)`.

Угловой коэффициент при `B != 0`:

`k = -A/B`.

Прямая через точку `M(x0,y0)` с угловым коэффициентом `k`:

`y-y0 = k(x-x0)`.

Прямая через две точки `A(x1,y1)`, `B(x2,y2)`:

`(x-x1)/(x2-x1) = (y-y1)/(y2-y1)`.

### Параллельность и перпендикулярность

Для прямых `A1x+B1y+C1=0` и `A2x+B2y+C2=0`:

Параллельность:

`A1*B2 - A2*B1 = 0`.

Перпендикулярность:

`A1*A2 + B1*B2 = 0`.

Чтобы провести параллельную данной прямой через точку, сохраняем коэффициенты `A,B` и находим новый `C` подстановкой точки.

Чтобы провести перпендикулярную, можно заменить нормаль `(A,B)` на `(B,-A)` и затем найти `C` по точке.

### Точка пересечения

Решить систему двух линейных уравнений прямых.

### Расстояние от точки до прямой

Для точки `M(x0,y0)` и прямой `Ax+By+C=0`:

`d = |A*x0 + B*y0 + C| / sqrt(A^2+B^2)`.

### Расстояние между параллельными прямыми

Если коэффициенты при `x,y` одинаковы:

`Ax+By+C1=0`, `Ax+By+C2=0`,

то

`d = |C1-C2| / sqrt(A^2+B^2)`.

### Угол между прямыми

Через нормали:

`cos φ = |A1*A2 + B1*B2| / (sqrt(A1^2+B1^2)*sqrt(A2^2+B2^2))`.

Через угловые коэффициенты:

`tan φ = |(k2-k1)/(1+k1*k2)|`.

### Уравнение по отрезкам на осях

`x/a + y/b = 1`.

Точки пересечения с осями: `(a,0)` и `(0,b)`.

### Медиана треугольника

1. Найти середину противоположной стороны:
   `M((x1+x2)/2, (y1+y2)/2)`.
2. Составить прямую через вершину и найденную середину.

### Высота треугольника

1. Составить уравнение противоположной стороны.
2. Через нужную вершину провести прямую, перпендикулярную этой стороне.

### Серединный перпендикуляр

1. Найти середину отрезка.
2. Найти направление исходного отрезка.
3. Через середину провести перпендикулярную прямую.

### Биссектрисы двух прямых

Для `A1x+B1y+C1=0` и `A2x+B2y+C2=0`:

`(A1x+B1y+C1)/sqrt(A1^2+B1^2) = ±(A2x+B2y+C2)/sqrt(A2^2+B2^2)`.

### Геометрическое место точек на фиксированном расстоянии от прямой

Положить формулу расстояния равной заданному `d`:

`|Ax+By+C|/sqrt(A^2+B^2)=d`.

После раскрытия модуля обычно получаются две параллельные прямые.

### Приоритет для подготовки

1. Прямая через две точки.
2. Параллельная/перпендикулярная через заданную точку.
3. Пересечение двух прямых.
4. Расстояние от точки до прямой.
5. Медиана/высота треугольника.
6. Угол между прямыми.
7. Биссектрисы.
8. Геометрическое место точек.

## Задание 3. Кривые второго порядка

### Как распознать кривую

- Окружность: `x^2 + y^2 = R^2`.
- Эллипс: `x^2/a^2 + y^2/b^2 = 1`.
- Гипербола: `x^2/a^2 - y^2/b^2 = 1` или наоборот.
- Парабола: `y^2 = 2px` или `x^2 = 2py`.

### Окружность

`(x-a)^2 + (y-b)^2 = R^2`.

Центр: `(a,b)`.
Радиус: `R`.

### Эллипс

Для `x^2/a^2 + y^2/b^2 = 1`, `a>b`:

- вершины: `(±a,0)`, `(0,±b)`;
- `c^2 = a^2 - b^2`;
- фокусы: `(±c,0)`;
- эксцентриситет: `e=c/a`, причём `0<e<1`;
- директрисы: `x=±a/e = ±a^2/c`.

Если больший знаменатель под `y^2`, большая ось вертикальная и фокусы имеют вид `(0,±c)`.

### Гипербола

Для `x^2/a^2 - y^2/b^2 = 1`:

- вершины: `(±a,0)`;
- `c^2 = a^2 + b^2`;
- фокусы: `(±c,0)`;
- эксцентриситет: `e=c/a > 1`;
- директрисы: `x=±a/e = ±a^2/c`;
- асимптоты: `y=±(b/a)x`.

Для `y^2/a^2 - x^2/b^2 = 1`:

- вершины: `(0,±a)`;
- фокусы: `(0,±c)`;
- асимптоты: `y=±(a/b)x`.

### Парабола

В обозначениях учебника:

`y^2 = 2px`.

- вершина: `(0,0)`;
- фокус: `(p/2,0)`;
- директриса: `x=-p/2`;
- `p>0` — ветви вправо, `p<0` — влево.

`x^2 = 2py`.

- фокус: `(0,p/2)`;
- директриса: `y=-p/2`;
- `p>0` — вверх, `p<0` — вниз.

### Эксцентриситет

- эллипс: `0<e<1`;
- парабола: `e=1`;
- гипербола: `e>1`.

### Касательные

Эллипс `x^2/a^2 + y^2/b^2 = 1` в точке `(x0,y0)`:

`x*x0/a^2 + y*y0/b^2 = 1`.

Гипербола `x^2/a^2 - y^2/b^2 = 1`:

`x*x0/a^2 - y*y0/b^2 = 1`.

Парабола `y^2=2px`:

`y*y0 = p(x+x0)`.

### Наиболее вероятные номера по блокам

- окружность: №390, 392, 396, 419;
- эллипс: №445, 449, 450, 457;
- гипербола: №516, 519, 525, 560;
- парабола: №585, 587, 590, 593.

### Что помнить наизусть

Эллипс: `c^2=a^2-b^2`.

Гипербола: `c^2=a^2+b^2`.

Парабола: `y^2=2px` или `x^2=2py`, фокус расположен на половине параметра `p` от вершины.
