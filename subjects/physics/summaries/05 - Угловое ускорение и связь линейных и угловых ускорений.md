# 05 — Угловое ускорение — краткая версия

Полная запись по фотографии: [[../notes/05 - Угловое ускорение и связь линейных и угловых ускорений]].

Угловое ускорение — первая производная угловой скорости по времени и вторая производная угла поворота.

$$\vec\varepsilon=\frac{d\vec\omega}{dt}=\frac{d^2\vec\varphi}{dt^2},\qquad [\varepsilon]=\mathrm{рад/с^2}.$$

При разгоне $\vec\varepsilon$ сонаправлено с $\vec\omega$; при замедлении — противоположно.

$$v=\omega R,\qquad a_\tau=R\varepsilon,\qquad a_n=\omega^2R.$$

$$\vec v=\vec\omega\times\vec r.$$

$$\vec a=(\vec\varepsilon\times\vec r)+(\vec\omega\times\vec v).$$
