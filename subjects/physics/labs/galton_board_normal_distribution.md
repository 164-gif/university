# Лабораторная работа — доска Гальтона и нормальное распределение

Источник восстановления: фотографии методички от 23.09.2026.

## Идея опыта

В работе статистические закономерности изучаются на доске Гальтона.

Доска представляет собой наклонную поверхность с набитыми гвоздями. Внизу расположены равные ячейки. Сверху через воронку высыпаются шарики или другие частицы.

При падении отдельной частицы её конечную ячейку заранее определить невозможно из-за множества случайных факторов. При большом числе частиц появляется статистическая закономерность распределения по ячейкам.

Чаще всего частицы попадают в центральные ячейки, реже — в крайние.

## Нормальное распределение

В методичке приведена функция нормального распределения и графики для разных значений параметра (sigma).

Смысл параметров по подписи:
- (x_k) — номер ячейки / значение случайной величины;
- (Delta x_k) — шаг случайной величины или размер бина;
- (sigma) — ширина функции распределения;
- (ar X) — среднее значение случайной величины.

## Порядок выполнения

1. Последовательно взять:
   - (N=50),
   - (N=100),
   - (N=300) шариков.

2. Для каждого (N) высыпать шарики через воронку и подсчитать число шариков (n_k) в каждой ячейке.

3. Для каждой ячейки рассчитать частоту:

[
F_k=rac{n_k}{N}.
]

4. Заполнить таблицы для каждого значения (N).

5. Построить гистограмму для дискретных значений:
   - по горизонтали — номер/значение ячейки;
   - высота прямоугольника определяется частотой (F_k).

6. Для случая (N=300) провести плавную кривую через экспериментальные точки.

7. По высоте кривой определить (sigma) согласно указанию методички.

8. По известным (ar X) и (sigma) вычислить теоретическое распределение шариков по ячейкам и нанести его на тот же график.

9. Сравнить экспериментальную и теоретическую кривые.
