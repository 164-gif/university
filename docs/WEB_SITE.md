# Веб-версия конспектов

Репозиторий автоматически публикуется как статический сайт через GitHub Pages.

## Что поддерживается

Сайт читает те же материалы, что используются в Obsidian, без отдельной копии конспектов:

- Markdown (`.md`);
- текстовые материалы (`.txt`);
- YAML frontmatter / Properties;
- Obsidian `[[wikilinks]]`;
- Obsidian embeds `![[...]]`;
- Callouts вида `> [!note]`, `> [!warning]` и т. п.;
- LaTeX/MathJax-синтаксис `$...$` и `$$...$$` через KaTeX;
- таблицы, списки, task lists и fenced code blocks;
- Mermaid-диаграммы;
- SVG, PNG, JPG/JPEG, WEBP, GIF, AVIF;
- PDF;
- MP3/WAV/OGG/M4A;
- MP4/WEBM.

## Интерфейс

- навигация по предметам и типам материалов;
- полнотекстовый поиск (`/` или `Ctrl/Cmd + K`);
- светлая и тёмная тема с запоминанием выбора;
- мобильное меню;
- breadcrumbs;
- автоматическое оглавление текущей заметки;
- поддержка прямых ссылок на заметки и заголовки;
- изображения и схемы из `notes/assets/` отображаются непосредственно в тексте.

## Как работает публикация

`web/build_site.py` сканирует `subjects/` и строит `_site/content.json`, после чего копирует поддерживаемые медиафайлы с сохранением структуры путей.

GitHub Actions workflow `.github/workflows/pages.yml` запускается после изменений в `subjects/**`, `web/**`, `README.md` или самом workflow и публикует `_site` в GitHub Pages.

Основные файлы интерфейса:

- `web/index.html`;
- `web/styles.css`;
- `web/app.js`;
- `web/build_site.py`.

## Правило для новых форматов

Если в учебных материалах появляется новый формат, который должен отображаться в браузере, нужно одновременно:

1. добавить расширение в `ASSET_EXTS` или `DOC_EXTS` в `web/build_site.py`;
2. добавить соответствующий renderer в `web/app.js`, если браузер не может открыть формат самостоятельно;
3. проверить светлую и тёмную тему;
4. проверить мобильную версию;
5. не менять исходные Obsidian-файлы только ради веб-версии.

## Локальная проверка

```bash
python3 web/build_site.py
python3 -m http.server 8000 -d _site
```

После этого открыть `http://localhost:8000`.
