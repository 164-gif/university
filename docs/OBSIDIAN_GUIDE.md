# Правила оформления для Obsidian

## Заголовки

- `#` — название лекции/темы.
- `##` — крупный раздел.
- `###` — подраздел.
- Не делать отдельный заголовок для каждого предложения.

## Связи

Wikilinks использовать для устойчивых сущностей:
- `[[Термин]]`
- `[[Лекция 03 — ...]]`
- `[[Формула ...]]`

Не создавать ссылку на слово только ради наличия ссылки.

## Callout-блоки

Рекомендуемые случаи:
- `[!important]` — то, что преподаватель явно выделил;
- `[!definition]` — ключевое определение;
- `[!warning]` — типичная ошибка;
- `[!question]` — вероятный вопрос на контроль.

## Формулы

Формулы хранить в LaTeX, если запись читается уверенно. Если часть выражения неизвестна, не восстанавливать её автоматически.
