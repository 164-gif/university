# Проверка качества учебного материала

Перед сохранением результата проверить:

## Достоверность
- [ ] Нет выдуманного текста.
- [ ] Все сомнительные места явно помечены.
- [ ] Неизвестные числа, даты и фамилии не восстановлены по догадке.
- [ ] Формулы не «исправлены» без подтверждения.
- [ ] Внешние дополнения отделены от содержания исходника.

## Полнота
- [ ] Сохранены определения.
- [ ] Сохранены перечисления и классификации.
- [ ] Сохранены примеры преподавателя.
- [ ] Сохранены важные замечания.
- [ ] Не потеряны оговорки и условия применения формул.

## Структура
- [ ] Исходник не перезаписан.
- [ ] Transcript и note существуют как разные сущности.
- [ ] Полная версия не заменена кратким summary.
- [ ] Материал лежит в правильной папке предмета.

## Учебная ценность
- [ ] Есть блок «Что важно запомнить».
- [ ] При необходимости выделены термины и формулы.
- [ ] Вопросы для самопроверки не выданы за слова преподавателя.

## Визуальные материалы
- [ ] Все содержательные рисунки из исходника перенесены.
- [ ] Рисунки не содержат додуманных подписей или деталей.
- [ ] Восстановленные изображения имеют ссылку на исходную страницу/файл.
- [ ] Дополнительные иллюстрации явно отделены от исходных.
- [ ] Дополнительные иллюстрации основаны на достоверной информации.

## Проверка фактов
- [ ] Проверяемые утверждения при необходимости сверены с надёжными источниками.
- [ ] Найденные расхождения не были молча исправлены в основном конспекте.
- [ ] Для сомнительных мест обновлён `checks/There might be a mistake.md`.
- [ ] В отчёте указано точное место, исходный фрагмент и причина сомнения.
- [ ] Указано, что вероятно нужно исправить.
- [ ] Указан уровень уверенности.
- [ ] Указан источник проверки, если проверка выполнялась по внешнему источнику.
