# Проверка качества учебного материала

Перед сохранением результата проверить:

## Достоверность
- [ ] Нет выдуманного текста.
- [ ] Все сомнительные места явно помечены.
- [ ] Неизвестные числа, даты и фамилии не восстановлены по догадке.
- [ ] Формулы не «исправлены» без подтверждения.
- [ ] Внешние дополнения отделены от содержания исходника.

## Полнота
- [ ] Сохранены определения.
- [ ] Сохранены перечисления и классификации.
- [ ] Сохранены примеры преподавателя.
- [ ] Сохранены важные замечания.
- [ ] Не потеряны оговорки и условия применения формул.

## Структура
- [ ] Исходник не перезаписан.
- [ ] Transcript и note существуют как разные сущности.
- [ ] Полная версия не заменена кратким summary.
- [ ] Материал лежит в правильной папке предмета.

## Учебная ценность
- [ ] Есть блок «Что важно запомнить».
- [ ] При необходимости выделены термины и формулы.
- [ ] Вопросы для самопроверки не выданы за слова преподавателя.
