# Pipeline аудио- и видеолекций

## Цель

Получить проверяемую цепочку от исходной записи до учебного конспекта, не смешивая распознавание речи и последующую редактуру.

## Этапы

1. **Исходник**
   - сохранить исходный файл без изменений;
   - записать дату, предмет и тему, если известны.

2. **Сегментация**
   - делить длинную запись по естественным паузам;
   - предпочтительно 5–20 секунд на сегмент;
   - не разрывать фразу посередине без необходимости;
   - допускается небольшой overlap для сложных стыков.

3. **ASR / RAW**
   - получить первичную расшифровку;
   - не исправлять неизвестные термины «по смыслу»;
   - сохранить таймкоды, если ASR их выдаёт.

4. **CLEAN transcript**
   - убрать технический мусор, явные повторы и слова-паразиты;
   - восстановить пунктуацию и абзацы;
   - сохранить все содержательные детали и примеры.

5. **Учебная обработка**
   - полный конспект;
   - краткий конспект;
   - определения и термины;
   - формулы;
   - важные тезисы;
   - возможные вопросы к зачёту/экзамену;
   - связи с предыдущими лекциями, только если они подтверждаются материалами репозитория.

## Контроль качества

На каждом этапе хранить сомнительные места. Следующая модель не имеет права молча превращать `[неразборчиво]` в уверенный текст.
