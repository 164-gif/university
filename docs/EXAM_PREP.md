# Подготовка к зачёту и экзамену

Материалы в `exam/` строятся только после готового полного конспекта.

## Из каждого блока лекций извлекать

- ключевые определения;
- классификации;
- формулы и условия их применения;
- важные даты и фамилии;
- причинно-следственные связи;
- примеры, которые преподаватель разбирал подробно;
- прямые указания «это будет на экзамене/зачёте», если они были.

## Форматы

Можно создавать:
- `questions.md` — вопросы;
- `answers.md` — развёрнутые ответы;
- `quick-review.md` — повторение перед занятием;
- `formulas.md` — формулы и обозначения;
- `terms.md` — словарь.

Нельзя выдавать самостоятельно придуманный вопрос за вопрос преподавателя. Такие вопросы маркировать как «вопрос для самопроверки».
