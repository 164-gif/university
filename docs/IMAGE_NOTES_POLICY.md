# Работа с фотографиями конспектов

## Порядок

1. Установить порядок страниц.
2. Для каждой страницы сначала понять общую структуру.
3. Затем распознавать заголовки, основной текст, поля, формулы и подписи.
4. Сверять неясные слова с соседними страницами.
5. Отдельно выписать места, которые невозможно прочитать.

## Нельзя

- достраивать окончание формулы по типовой формуле из учебника;
- заменять нечитаемую фамилию знакомой фамилией «по теме»;
- дописывать отсутствующий пункт списка;
- менять число только потому, что другое число кажется логичнее;
- смешивать текст разных страниц.

## Допустимая редактура в notes/

После точной фиксации исходного содержания можно:
- раскрыть структуру заголовками;
- объединить оборванные строки;
- оформить формулы;
- исправить очевидные орфографические ошибки, не меняющие термин;
- убрать повторы.

Все содержательные реконструкции должны быть явно помечены.
