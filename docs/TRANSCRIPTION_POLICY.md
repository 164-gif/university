# Политика расшифровки

## Принцип

Точность важнее гладкости. Если фрагмент нельзя подтвердить по исходнику, его нельзя незаметно «исправить» или дополнить.

## Стандартные обозначения

- `[неразборчиво]` — слово или короткий фрагмент нельзя уверенно распознать.
- `[неразборчиво, ~N слов]` — известен приблизительный объём пропуска.
- `[предположительно: ...]` — вероятный вариант, уверенности недостаточно.
- `[имя/термин неразборчив]` — нельзя надёжно определить имя или термин.
- `[формула неразборчива]` — формулу нельзя восстановить без домысливания.
- `[пропуск в исходнике]` — материал отсутствует физически.

## RAW и CLEAN

### RAW transcript
Максимально близок к исходной речи/записи:
- сохраняет порядок;
- сохраняет смысловые повторы;
- содержит пометки неуверенности;
- не нормализует неизвестные термины без проверки.

### CLEAN transcript / note
Можно:
- убрать слова-паразиты;
- убрать случайные повторы;
- исправить пунктуацию;
- разбить материал по темам;
- раскрыть очевидные местоименные ссылки, если смысл не меняется.

Нельзя:
- добавлять новые факты;
- менять позицию преподавателя;
- превращать гипотезу в утверждение;
- исправлять числа и формулы «по учебнику» без отдельной отметки.

## Проверка сомнительных мест

Если возможно, использовать:
1. соседний контекст;
2. повтор того же термина позже;
3. слайд/доску/фото;
4. другой фрагмент записи.

Если подтверждения нет — оставить метку неуверенности.
