# Правила хранения материалов

## Не перезаписывать исходники

Любой исходный файл сохраняется как источник. Производный Markdown/текст не заменяет исходник.

## Имена файлов

Для учебных материалов, которые показываются пользователю как последовательность тем, использовать нумерацию по образцу физики:

`NN - Название темы.md`

Примеры:
- `01 - Введение и основные понятия.md`
- `02 - Следующая тема.md`
- `03 - Подготовка по следующему блоку.md`

Это правило распространяется прежде всего на:
- `notes/`;
- `summaries/`;
- `concepts/`;
- `exam/`.

Нумерация должна отражать учебный порядок тем, а не случайный алфавитный порядок. Если появляется новая тема между уже существующими, сначала проверить, можно ли поставить её в конец без искажения учебной последовательности; массово перенумеровывать старые файлы без необходимости не следует, чтобы не ломать ссылки.

Для `raw/` и точных исходных материалов допускается сохранять дату и исходное имя, например:
`YYYY-MM-DD_topic_type.md`.

Примеры для исходников:
- `2026-09-10_vvedenie_transcript.md`
- `2026-09-10_vvedenie_source.md`

На веб-сайте старые ненумерованные материалы дополнительно нормализуются и показываются с последовательными номерами, чтобы навигация была единообразной даже без опасного переименования старых файлов.

## Версионность

Если конспект исправлен после повторной проверки исходника:
- изменения должны быть осмысленными;
- не удалять отметки сомнения без подтверждения;
- при существенном исправлении кратко фиксировать, что было уточнено.

## Связь материалов

В начале производного файла желательно указывать:
- исходный файл;
- дату;
- предмет;
- тип преобразования;
- наличие неразборчивых мест.

## Запрет

Нельзя копировать в `notes/` текст из внешнего учебника и выдавать его за содержание лекции.
