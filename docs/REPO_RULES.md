# Правила хранения материалов

## Не перезаписывать исходники

Любой исходный файл сохраняется как источник. Производный Markdown/текст не заменяет исходник.

## Имена файлов

Предпочтительный формат:
`YYYY-MM-DD_topic_type.md`

Примеры:
- `2026-09-10_vvedenie_transcript.md`
- `2026-09-10_vvedenie_notes.md`
- `2026-09-10_vvedenie_summary.md`

## Версионность

Если конспект исправлен после повторной проверки исходника:
- изменения должны быть осмысленными;
- не удалять отметки сомнения без подтверждения;
- при существенном исправлении кратко фиксировать, что было уточнено.

## Связь материалов

В начале производного файла желательно указывать:
- исходный файл;
- дату;
- предмет;
- тип преобразования;
- наличие неразборчивых мест.

## Запрет

Нельзя копировать в `notes/` текст из внешнего учебника и выдавать его за содержание лекции.
