# Какие AI работают с University Notes

## Обычные AI-приложения на Android — без ПК, CLI и настройки репозитория

Это главный раздел для обычного пользователя. Нужно просто установить приложение на Android, открыть новый чат и отправить готовый промпт из University Notes.

Статусы ниже относятся именно к **обычному мобильному приложению**, а не к CLI, IDE, coding-agent или локальному клону репозитория.

| AI | Android | University Notes по готовому промпту | Статус |
|---|---|---|---|
| **ChatGPT** | ✅ | ✅ поддерживает | **Рекомендуется** |
| **Qwen** | ✅ | ✅ поддерживает | **Рекомендуется** |
| **Claude** | ✅ | ✅ поддерживает | **Рекомендуется** |
| **Gemini** | ✅ | ❌ не поддерживает этот способ | Не рекомендуется |
| **DeepSeek** | ✅ | ❌ не поддерживает этот способ | Не рекомендуется |

### ChatGPT

**Статус: ✅ работает в обычном Android-приложении.**

Пользователю достаточно скопировать готовый промпт из раздела AI и отправить его в обычный чат ChatGPT. Если на аккаунте доступен GitHub-коннектор, ChatGPT также может получать разрешённое содержимое репозитория напрямую.

### Qwen

**Статус: ✅ работает в обычном Android-приложении.**

Для пользователя не нужен Qwen Code, терминал или компьютер: можно использовать обычный Qwen Chat на телефоне и отправить готовый промпт.

### Claude

**Статус: ✅ работает в обычном Android-приложении.**

Можно использовать обычный Claude на телефоне без Claude Code и без клонирования репозитория.

### Gemini

**Статус: ❌ в обычном Android-приложении этот способ не работает.**

В наших проверках Gemini не смог нормально получить University Notes через подготовленную ссылку. Gemini CLI на ПК — отдельный режим и к этому мобильному статусу не относится.

### DeepSeek

**Статус: ❌ в обычном Android-приложении этот способ не работает.**

DeepSeek может открыть часть входной информации, но не обеспечивает стабильный доступ ко всем материалам University Notes через обычный мобильный чат.

## Что выбрать на телефоне

Если пользователь хочет просто открыть приложение и пользоваться без настройки:

1. **ChatGPT** — рекомендуется.
2. **Qwen** — рекомендуется.
3. **Claude** — рекомендуется.
4. **Gemini** — не использовать для этого способа.
5. **DeepSeek** — не использовать для этого способа.

Для ChatGPT, Qwen и Claude используется один и тот же готовый промпт из пользовательского AI-раздела.

## Как пользоваться на Android

1. Открыть University Notes.
2. Перейти в раздел **«Работа с AI»**.
3. Нажать **«Копировать промпт»**.
4. Открыть ChatGPT, Qwen или Claude.
5. Вставить промпт в новый чат.
6. После успешного ознакомления AI должен подтвердить готовность маркером `⟦UNIV-AI-READY⟧`.
7. После этого можно задавать вопросы по лекциям, конспектам, тестам и другим материалам.

## Продвинутые варианты для ПК

Этот раздел нужен только тем, кому требуется максимально надёжный доступ ко всему дереву файлов, редактирование репозитория или работа coding-agent.

### ChatGPT + GitHub

ChatGPT с подключённым GitHub может получать разрешённые файлы репозитория напрямую. Это более надёжный режим для больших задач по всему репозиторию.

### Qwen Code

Qwen Code работает внутри локальной папки проекта.

```bash
git clone https://github.com/164-gif/university.git
cd university
qwen
```

### OpenAI Codex

```bash
git clone https://github.com/164-gif/university.git
cd university
codex
```

### Claude Code

```bash
git clone https://github.com/164-gif/university.git
cd university
claude
```

### Gemini CLI

```bash
git clone https://github.com/164-gif/university.git
cd university
gemini
```

### Cursor Agent

Открыть локальную папку `university` в Cursor и использовать Agent.

### GitHub Copilot coding agent

Подходит для работы с репозиторием через GitHub, если соответствующий режим доступен на аккаунте.

## Стартовый запрос для локального агента

> Сначала прочитай `usethis.md`, `AGENTS.md` и `README.md`. Затем изучи структуру `subjects/` и связанные инструкции. Не выдумывай отсутствующие данные. При ответах на тесты сначала ищи подтверждённые ответы в `exam/`, затем материалы преподавателя в `notes/` и `transcripts/`.

## Важно

Мобильная совместимость выше основана на фактических проверках University Notes. Возможности приложений могут меняться, поэтому при изменении поведения конкретного AI таблицу нужно обновлять.
