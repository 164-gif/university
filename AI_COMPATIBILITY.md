# Какие AI работают с University Notes

## Обычные AI-приложения на Android — без ПК, CLI и настройки репозитория

Это главный раздел для обычного пользователя. Нужно просто установить приложение на Android, открыть новый чат и отправить готовый промпт из University Notes.

Статусы ниже относятся именно к **обычному мобильному приложению**, а не к CLI, IDE, coding-agent или локальному клону репозитория.

| AI | Android | University Notes по готовому промпту | Статус |
|---|---|---|---|
| **ChatGPT** | ✅ | ⚠️ лучше через GitHub | Отдельный режим |
| **Qwen** | ✅ | ⚠️ базовый доступ есть, полный тест не пройден | Ограниченно |
| **Claude** | ✅ | ✅ подтверждённо читает сайт | **Рекомендуется, есть лимит URL за ход** |
| **GLM / Z.ai** | ✅ | ✅ полный тест пройден | **Полностью подтверждено** |
| **Gemini** | ✅ | ❌ не поддерживает этот способ | Не рекомендуется |
| **DeepSeek** | ✅ | ❌ не поддерживает этот способ | Не рекомендуется |

### ChatGPT

**Статус:** для постоянной работы рекомендуется отдельный проект с подключённым GitHub.

Без GitHub доступ к GitHub Pages может зависеть от конкретного режима приложения. С подключённым GitHub ChatGPT может читать разрешённые файлы репозитория напрямую.

### Qwen

**Статус: ⚠️ базовый доступ работает, но полный тест не пройден.**

Qwen может открывать опубликованные материалы University Notes, однако текущая проверка не подтвердила доступ ко всем тестовым файлам. Поэтому Qwen пока нельзя считать полностью совместимым с сайтом.

Для обычных вопросов по отдельным материалам он может быть полезен, но для задач, где критично гарантированно прочитать весь набор источников, лучше использовать подтверждённый вариант.

### Claude

**Статус: ✅ подтверждённо работает в обычном Android-приложении и читает реальные файлы University Notes.**

В полном тесте Claude успешно открывал короткие ссылки `/ai/f/<id>.txt` и считывал контрольные `TEST_FRAGMENT` из файлов.

**Ограничение:** у Claude есть лимит количества веб-страниц/URL, доступных за один ход. В нашей проверке он прочитал **24 файла подряд из 132**, после чего остановился из-за лимита инструмента, а не из-за ошибки сайта.

Практически это означает:

- обычные вопросы по одному предмету, конспекту или нескольким файлам работают нормально;
- при массовом чтении десятков файлов может потребоваться продолжение в следующем сообщении;
- полный тест всего University Notes лучше проходить частями, продолжая с последнего проверенного номера.

### GLM / Z.ai

**Статус: ✅ полная совместимость подтверждена полным тестом University Notes.**

GLM / Z.ai успешно прошёл полный тест: открыл весь набор проверяемых файлов и собрал корректный итоговый ключ. Это подтверждает не только доступ к `AI_ENTRY.txt`, но и реальное чтение всех материалов из тестовой выборки.

На текущий момент это наиболее полно подтверждённый вариант для обычного мобильного использования через сайт.

### Gemini

**Статус: ❌ в обычном Android-приложении этот способ не работает.**

В наших проверках Gemini не смог нормально получить University Notes через подготовленную ссылку. Gemini CLI на ПК — отдельный режим и к этому мобильному статусу не относится.

### DeepSeek

**Статус: ❌ в обычном Android-приложении этот способ не работает.**

DeepSeek может открыть часть входной информации, но не обеспечивает стабильный доступ ко всем материалам University Notes через обычный мобильный чат.

## Что выбрать на телефоне

Для обычной работы без настройки:

1. **GLM / Z.ai** — полный тест пройден, сейчас самый подтверждённый вариант.
2. **Claude** — подтверждённо читает файлы сайта; учитывать лимит URL за один ход.
3. **Qwen** — базовый доступ есть, но полный тест не пройден.
4. **ChatGPT** — лучше использовать через отдельный проект и GitHub.
5. **Gemini** — не использовать для этого способа.
6. **DeepSeek** — не использовать для этого способа.

## Как пользоваться на Android

1. Открыть University Notes.
2. Перейти в раздел **«Работа с AI»**.
3. Нажать кнопку нужного AI.
4. Вставить промпт в новый чат.
5. После успешного ознакомления AI должен подтвердить готовность маркером `⟦UNIV-AI-READY⟧`.
6. После этого можно задавать вопросы по лекциям, конспектам, тестам и другим материалам.

Для проверки реального доступа ко всем опубликованным материалам используйте отдельный полный тест AI.

ChatGPT с подключённым GitHub может получать разрешённые файлы репозитория напрямую. Это более надёжный режим для больших задач по всему репозиторию.

## Стартовый запрос для локального агента

> Сначала прочитай `usethis.md`, `AGENTS.md` и `README.md`. Затем изучи структуру `subjects/` и связанные инструкции. Не выдумывай отсутствующие данные. При ответах на тесты сначала ищи подтверждённые ответы в `exam/`, затем материалы преподавателя в `notes/` и `transcripts/`.

## Важно

Мобильная совместимость выше основана на фактических проверках University Notes. Возможности приложений и их лимиты могут меняться, поэтому при изменении поведения конкретного AI таблицу нужно обновлять.
