# university

Репозиторий для университетских конспектов, расшифровок лекций, материалов из фотографий и подготовки к зачётам/экзаменам.

Главный принцип: **не выдумывать то, чего нет или невозможно уверенно разобрать в исходнике**.

Точка входа для нового AI-агента: [`usethis.md`](usethis.md). Достаточно передать ссылку на этот файл/репозиторий, после чего агент должен прочитать правила и работать по ним.

## Структура

```
subjects/<предмет>/
├── README.md
├── raw/          # исходные материалы
├── transcripts/  # максимально близкие к исходнику расшифровки
├── notes/        # очищенные полные конспекты
├── summaries/    # краткие версии
├── concepts/     # термины, определения, формулы
├── exam/         # подготовка к зачёту/экзамену
└── checks/       # возможные ошибки и результаты проверки

templates/        # шаблоны файлов
docs/             # общие правила и pipeline
```

## Базовый workflow

`исходник → точная расшифровка → очищенный конспект → краткий конспект → понятия/формулы → подготовка к контролю`

Исходник никогда не перезаписывается производной версией.

Перед работой агент обязан прочитать `AGENTS.md`, затем профиль соответствующего предмета и нужные инструкции из `docs/`.

Содержательные рисунки из исходников должны переноситься в чистовой конспект. Дополнительные визуализации разрешены только при высокой учебной пользе и должны быть достоверными.

Проверяемые факты можно сверять с внешними источниками, но найденные ошибки нельзя молча исправлять: они фиксируются в `checks/There might be a mistake.md`.

Состояние восстановления: `RECOVERY_STATUS.md`.
