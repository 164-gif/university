# university

Репозиторий для конспектов, расшифровок лекций и подготовки к экзаменам.

Главный принцип: **никогда не выдумывать текст, который не удалось разобрать**.

Структура:
- subjects/<предмет>/raw — исходные материалы;
- subjects/<предмет>/transcripts — дословные расшифровки;
- subjects/<предмет>/notes — очищенные конспекты;
- subjects/<предмет>/summaries — краткие версии;
- subjects/<предмет>/exam — материалы к зачёту/экзамену;
- templates — шаблоны;
- docs — правила работы агента.
