# university

Репозиторий для университетских конспектов, расшифровок лекций, материалов из фотографий и подготовки к зачётам/экзаменам.

Главный принцип: **не выдумывать то, чего нет или невозможно уверенно разобрать в исходнике**.

Точка входа для нового AI-агента: [`usethis.md`](usethis.md). Достаточно передать ссылку на этот файл/репозиторий, после чего агент должен прочитать правила и работать по ним.

## Учебные наборы

Материалы разделены по году и курсу:

- `ИБ-2026 — 1 курс` — сюда относятся **все текущие материалы** из `subjects/`;
- `ИБ-2025 — 1 курс` — пока пустой;
- `ИБ-2026 — 2 курс` — пока пустой.

### Важно: куда писать новые материалы

Структуру `subjects/` **оставляем как есть навсегда для ИБ-2026 — 1 курс**. Ничего из неё не переносим.

Все новые материалы именно для `ИБ-2026 — 1 курс` продолжаем писать по старым путям:

```text
subjects/<предмет>/...
```

Все остальные учебные наборы пишем уже только по новой схеме:

```text
cohorts/<набор>/subjects/<предмет>/...
```

Например:

```text
cohorts/ib-2025-1kurs/subjects/<предмет>/...
cohorts/ib-2026-2kurs/subjects/<предмет>/...
```

Это правило нужно соблюдать и людям, и AI-агентам. Старый `subjects/` не мигрировать в `cohorts/ib-2026-1kurs/subjects/`, чтобы не ломать Obsidian-ссылки, SVG/медиа-ссылки, историю репозитория и уже существующие пути.

Подробно: [`docs/COHORT_STRUCTURE.md`](docs/COHORT_STRUCTURE.md).

## Веб-версия

Материалы автоматически публикуются как сайт через GitHub Pages. Веб-интерфейс использует те же файлы, что и Obsidian, поэтому отдельную копию конспектов поддерживать не нужно.

Поддерживаются:
- Markdown и TXT;
- `$...$` и `$$...$$` LaTeX-формулы через KaTeX;
- `[[wikilinks]]` и `![[embeds]]` Obsidian;
- callouts;
- Mermaid;
- SVG, PNG, JPG/JPEG, WEBP, GIF, AVIF;
- PDF;
- аудио и видео;
- светлая и тёмная тема;
- полнотекстовый поиск;
- навигация по учебным наборам, предметам, разделам и заголовкам;
- мобильная версия.

Исходники сайта: `web/`. Документация: [`docs/WEB_SITE.md`](docs/WEB_SITE.md).

После включения GitHub Pages сайт доступен по адресу `https://164-gif.github.io/university/` и автоматически пересобирается после обновлений `main`.

## Структура

```text
subjects/<предмет>/        # постоянное место для ИБ-2026 — 1 курс
├── README.md
├── raw/          # исходные материалы
├── transcripts/  # максимально близкие к исходнику расшифровки
├── notes/        # очищенные полные конспекты
├── summaries/    # краткие версии
├── concepts/     # термины, определения, формулы
├── exam/         # подготовка к зачёту/экзамену
└── checks/       # возможные ошибки и результаты проверки

cohorts/
├── ib-2025-1kurs/          # материалы писать в subjects/ внутри этого набора
├── ib-2026-1kurs/          # логический контейнер; текущий контент остаётся в корневом subjects/
└── ib-2026-2kurs/          # материалы писать в subjects/ внутри этого набора

# Для всех новых наборов, кроме текущего ИБ-2026 — 1 курс:
cohorts/<набор>/subjects/<предмет>/...

templates/        # шаблоны файлов
docs/             # общие правила и pipeline
web/              # веб-интерфейс и сборщик GitHub Pages
```

## Базовый workflow

`исходник → точная расшифровка → очищенный конспект → краткий конспект → понятия/формулы → подготовка к контролю`

Исходник никогда не перезаписывается производной версией.

Перед работой агент обязан прочитать `AGENTS.md`, затем профиль соответствующего предмета и нужные инструкции из `docs/`.

Содержательные рисунки из исходников должны переноситься в чистовой конспект. Дополнительные визуализации разрешены только при высокой учебной пользе и должны быть достоверными.

Проверяемые факты можно сверять с внешними источниками, но найденные ошибки нельзя молча исправлять: они фиксируются в `checks/There might be a mistake.md`.

Состояние восстановления: `RECOVERY_STATUS.md`.
