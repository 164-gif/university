# University Tokenizer v0.1 — этап 04

Собственная реализация byte-level BPE на Python 3.10+, без внешних библиотек.
Начальный словарь: 4 специальных токена (PAD=0, BOS=1, EOS=2, MASK=3) и 256 байтов UTF-8 (ID 4–259). Неизвестных символов нет для валидного Unicode. Сегментация сохраняет регистр, ё, пробелы, переносы, математические символы и LaTeX. Команды LaTeX, слова, числа и пунктуация сегментируются отдельно. BPE обучается на частотах соседних пар внутри сегментов. При равенстве частот выбирается лексикографически меньшая пара ID. Обучение заканчивается при достижении 16384 токенов или отсутствии пар с частотой >=2. Размер словаря будущей модели берётся из сохранённого файла, а не жёстко задаётся как 16384.

```bash
python3 -m ai.indexing.build_index
python3 -m ai.tokenizer.train
python3 -m unittest discover -s ai/tests -v
```

Артефакты: ai/generated/tokenizer.json (упорядоченные пары ID, компактный формат), ai/generated/tokenizer-report.json (метрики и хеши). Обучение использует весь индекс без точных дублей; метрики сжатия измерены на обучающем корпусе, не на независимой выборке. Код не меняет BM25F и исходный Markdown.

```python
from pathlib import Path
from ai.tokenizer.bpe import BPETokenizer
tok = BPETokenizer.load(Path("ai/generated/tokenizer.json"))
ids = tok.encode("Скалярное произведение")
assert tok.decode(ids) == "Скалярное произведение"
batch = tok.model_inputs("Скалярное произведение", max_length=512)
```

Вход будущего encoder: input_ids и attention_mask длиной 512. По умолчанию превышение контекста вызывает ошибку; явное truncate=True позволяет отсечь последовательность (может разрезать многобайтовый символ; усечённая последовательность предназначена для encoder, а не для дословного ответа). Текст ответа хранится отдельно. На этапе 06 длинные фрагменты потребуется разбивать по смыслу и проверять соответствие источнику.

Токенизатор обучен частотам, а не семантике. Совместимость с браузером, экспорт в JS и нейросетевое качество пока не проверены. Не переобучать словарь после обучения encoder без совместимого переобучения весов. Хеш словаря необходимо фиксировать в checkpoint.
