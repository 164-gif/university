# University AI v0.3 — банк вопросов

Отдельная экспериментальная ветка. Исходные учебные материалы не изменяются. Построение выполняется только по материалам текущего checkout, без внешних API. Новые вопросы не являются вопросами преподавателя.

Команда: python -m ai.question_bank.build --output ai/data/v03

Артефакты: existing.jsonl (извлечённые вопросы), generated.jsonl (ровно 1000 новых уникальных формулировок), typos.jsonl (до 5 искажений каждого размеченного вопроса), review.jsonl (без надёжной привязки), passages.jsonl (дословные фрагменты), train/validation/test-examples.jsonl, manifest.json.

Разметка:
- source_answer: в источнике есть явный ответ, это не означает независимую проверку правильности.
- authored: составленные вручную смысловые формулировки с точным якорем в источнике.
- generated_weak: программно составленные вопросы по определениям/заголовкам и имеющимся вопросам; требуют выборочной ручной проверки.
- review: вопросы без прямого ответа либо сомнительная разметка; не используются как положительные примеры. BM25-кандидаты только для разметчика.

Сохраняются исходные вопросы, путь/строки/хеш фрагмента, предмет, курс, positive_ids, parent_id, тип происхождения и split. Разделение совместимо с v0.2: математический анализ — validation, ОРГ — test, остальные — train. Перефразировки и опечатки наследуют split. Не использовать test/validation для обучения и настройки токенизатора. Это слабая разметка, не независимый контрольный тест; новый тест на реальных студенческих запросах нужен отдельно.

Генератор опечаток отдельно: python -m ai.question_bank.typos --input ai/data/v03/existing.jsonl ai/data/v03/generated.jsonl --output /tmp/typos.jsonl --variants 5 --seed 42. Неподтверждённые вопросы без positive_ids пропускаются. Исходные ответы/формулы/числа/отрицания не изменяются. Генерируются перестановки соседних букв, пропуск, повтор, замена на соседнюю клавишу и неверная раскладка. Совпадения с чистыми вопросами и другими группами исключаются. Варианты не гарантированно существуют в естественной речи.

В обучении использовать только train-examples.jsonl, сравнить сначала source_answer+authored с добавлением generated_weak, затем с шумом. Для старого full_train надо подготовить совместимый датасет/manifest с актуальным train-only BPE; не подменять файлы старого эксперимента без проверки.
