# University AI — этап 02: индексирование

Экспериментальная ветка. Это подготовка корпуса, ещё не языковая модель и не поисковый движок.

## Запуск из корня репозитория

```bash
python3 -m ai.indexing.build_index
python3 -m unittest discover -s ai/tests -v
```

Без сторонних зависимостей (Python 3.10+). Индекс хранится в `ai/generated/` и не коммитится.

- `passages.jsonl` — один фрагмент на строку: исходный Markdown, предмет, набор, слой, цепочка заголовков, диапазон строк (1-based, включительно), SHA-256 источника и текста, предупреждения.
- `manifest.json` — версия схемы, статистика, хеш индекса, исходные файлы и commit HEAD (если доступен).

Сборщик читает `subjects/` и `cohorts/*/subjects/`; первый путь относится к ИБ-2026 — 1 курс. Индексируются учебные слои, в том числе экзаменационные вопросы и лабораторные. `raw/`, `checks/`, служебные файлы и вложения исключены из ответного корпуса; будущий отдельный слой предупреждений должен учитывать checks. Старые версии, пересказы и расшифровки не объединяются с чистовым конспектом. Никакие исходники не изменяются.

Разбиение идёт по заголовкам и абзацам, с сохранением явно распознанных пар вопрос–ответ, fenced code и формул с $$, без переписывания текста. 1000 символов — мягкая цель: целостная формула или ответ могут быть длиннее. Навигационные и чисто графические блоки пропускаются. Для полноценного ответа на вопрос об иллюстрации позже понадобится отдельный индекс медиа.

Предупреждения распознаются консервативно на уровне фрагмента и документа. Это эвристика, а не фактчекинг. Отсутствие флага не означает подтверждение преподавателем. Перед публичной интеграцией необходимо добавить проверку связанного checks, разрешение конфликтов, фильтр учебных наборов и отдельные политики для слоёв.

## Ограничения

- Markdown разбирается эвристически, не полным AST: нестандартные конструкции и длинные ответы требуют проверки на реальном корпусе.
- Не создан датасет перефразированных вопросов, токенизатор, эмбеддинги или обученные веса.
- Сайт и workflow Pages не изменены; этап не публикует новый интерфейс.
