# Этап 03 — BM25F

Запуск из корня:

```bash
python3 -m ai.indexing.build_index
python3 -m ai.search.cli "Что такое скалярное произведение?" --subject analytical_geometry --layer notes
python3 -m ai.evaluation.evaluate
python3 -m unittest discover -s ai/tests -v
```

BM25F объединяет частоты терминов в трёх полях: текст (1.0), ближайший заголовок (1.65), название файла (0.65). IDF вычисляется в отфильтрованном корпусе, нормализация длины использует статистику полного индекса. Нормализация русского языка эвристическая, без внешних зависимостей; опечатка исправляется только при одном кандидате на расстоянии одной редакции. По умолчанию курс ИБ-2026 — 1 курс, исключены расшифровки и краткие версии (можно выбрать явно через --layer). Полный оригинальный фрагмент, предупреждения, хеши и строки возвращаются без изменений. Совпадение менее половины значимых токенов отсекается. Это эвристика, не вероятность и не подтверждение ответа.

Набор questions.json — небольшой ручной smoke benchmark по реальным фрагментам, с заранее заданным предметом и слоем. Эталон задаётся путем и точной подстрокой, а при запуске разрешается в актуальные ID. Метрики Top-1, Top-5 и MRR@5 измеряют попадание в конкретный исходный фрагмент, не правильность фактов. Альтернативные корректные источники могут быть не размечены. Не является независимой тестовой выборкой для будущего обучения. Отрицательный пример проверяет отсутствие ответа только на заведомо бессмысленный запрос.
