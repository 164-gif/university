# Публичная бета University AI v0.2

Веса ONNX и токенизатор перенесены по точным Git blob ID из feature/university-ai-gpu (9b57cc01cb3a51e20fb56fd51bfada6d9d0d97d0). PyTorch checkpoint не переносится в main. Публикация Pages генерирует индекс из актуального корпуса тем же ONNX, проверяет SHA-256, исходные строки и эмбеддинги. Запросы обрабатываются браузером WASM, без внешнего API. Обычный поиск не изменён. Фильтры курса и предмета, до пяти кандидатов со ссылками. Нет проверенного порога отказа; результаты могут быть нерелевантными. Длинные неделимые и явно сомнительные фрагменты исключаются; предупреждения документов сохраняются. Запросы не собираются. Первый запуск требует загрузки модели, индекса и WASM.

Локальная сборка: npm ci --prefix ai/browser-runtime; python -m pip install numpy==2.2.6 onnxruntime==1.23.2; python web/build_site.py; python -m ai.publish_search; python -m http.server 8123 --directory _site. Обычная сборка сайта не требует Python-зависимостей AI.
