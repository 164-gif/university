# Публичная бета University AI v0.2

Веса ONNX и токенизатор перенесены по точным Git blob ID из feature/university-ai-gpu (9b57cc01cb3a51e20fb56fd51bfada6d9d0d97d0). PyTorch checkpoint не переносится в main. Публикация Pages генерирует индекс из актуального корпуса тем же ONNX, проверяет SHA-256, исходные строки и эмбеддинги. Запросы обрабатываются браузером WASM, без внешнего API. Обычный поиск не изменён. Фильтры курса и предмета, до пяти кандидатов со ссылками. Нет проверенного порога отказа; результаты могут быть нерелевантными. Длинные неделимые и явно сомнительные фрагменты исключаются; предупреждения документов сохраняются. Запросы не собираются. Первый запуск требует загрузки модели, индекса и WASM.

Локальная сборка (Python 3.12): npm ci --prefix ai/browser-runtime; python -m pip install --only-binary=:all: -r ai/browser-runtime/requirements.txt; python web/build_site.py; python -m ai.publish_search; python -m http.server 8123 --directory _site. Обычная сборка сайта не требует Python-зависимостей AI.

## Кеш и изоляция ошибок

Pages восстанавливает полный проверенный AI bundle по хешам кода, корпуса, модели и токенизатора. Если всё совпадает, не устанавливает AI-зависимости и не запускает inference/Chromium. При изменении корпуса пересчитываются только уникальные новые входы encoder; порядок строк и метаданные строятся заново, удалённые фрагменты не публикуются. SHA-256 и размеры каждого файла проверяются. Полная переиндексация при изменении идентичности векторов (веса, токенизатор, его реализация или версия Python-зависимостей). Chromium проверяется при изменении AI-кода или отсутствии подходящего кеша. Ветка обычного сайта публикуется даже при ошибке AI; непроверенный или устаревший индекс удаляется. AI-этап имеет ограничение 6 минут, Python 3.12 и только бинарные wheels. Кеш GitHub Actions может быть вытеснен, тогда потребуется холодная сборка. Локальный кеш .ai-search-cache/bundle не следует коммитить.

## Гибридный поиск

По умолчанию BM25F с нормализацией русских слов, ё/е и математических символов. Для неизвестного термина допускается одна вставка/удаление/замена или перестановка соседних букв, только если кандидат однозначен в выбранном курсе/предмете либо однозначно подтверждён другими терминами. Числа не исправляются. Первый лексический результат сохраняется, нейросеть может переставлять близкие по лексическому баллу кандидаты (90% lexical RRF, 10% semantic RRF), при отсутствии лексики — явно обозначенный semantic-only. Это новая консервативная эвристика, а не повторное обучение. Пользователь может выбрать BM25F или чистый ИИ. Нет калиброванного порога отказа.
