# University AI v0.3

Ветка экспериментов `feature/university-ai-v03-training` основана на GPU ветке. Данные `ai/data/v03` импортированы без изменений из `eeb8dc58761a1ac339485602cc9072b686f39901`. Внутренний `source_commit` `feaa746d2e9a0662ad2fc0748da621f890a50332` указывает на исходные учебные материалы, из которых собраны фрагменты.

## Как воспроизвести

Понадобятся Linux, CUDA и Python окружение University AI. Для экспорта требуются `onnx` и `onnxruntime`. Проверка браузера использует Chromium, Node с поддержкой WebSocket и зависимости `npm ci --prefix web`.

```bash
.venv/bin/python -m ai.training.validate_v03
.venv/bin/python -m unittest discover -s ai/tests -q
node --test web/ai-search-tokenizer.test.mjs
.venv/bin/python -m ai.training.v03_suite
```

Пайплайн использует сохранённые `ai/generated/full/dataset/test-examples.jsonl` и `test-passages.jsonl` из старого эксперимента. Их SHA-256 фиксируются в аудите. Если эти файлы хранятся отдельно, передайте путь к старым запросам через `--legacy`. Для учителя Cross-Encoder можно передать `--local-cross-teacher` с файлами закреплённой ревизии. Веса учителей скачиваются с Hugging Face, вычисления выполняются локально.

`v03_suite` выбирает учителя и конфигурации на Validation, выполняет по 50 основных эпох для A, B и C, затем оценивает замороженный выбор и экспортирует лучшую отдельную модель. Повторный запуск продолжает основное обучение по последнему checkpoint при совпадении конфигурации, данных и SHA-256 токенизатора. Для отдельно запущенного эксперимента передайте те же аргументы и `--resume`. Сохранённый checkpoint содержит оптимизатор, scheduler, GradScaler, номер шага и состояния генераторов. MLM имеет отдельный checkpoint после пяти эпох.

## Данные и выбор модели

Валидатор проверяет все десять файлов из манифеста, включает проверку подмножеств `*-extra` и сверяет 2 249 фрагментов по строкам в 160 Git-источниках. Совпадение записей и первоисточников не делает автоматически сгенерированные ответы подтверждёнными. Непроверенные метки получают меньший вес. Для 1 033 записей из `review.jsonl` сохраняются кандидаты со ссылками на строки, без превращения совпадений BM25F в разметку. Фильтр близких повторов использует символьные шинглы и раздельные предметы, поэтому не гарантирует отсев всех смысловых дублей.

Каждое семейство даёт один запрос за эпоху. Выбор 20%, 40% или 50% опечаток проверен совместно с разными весами слабых меток, дистилляции и согласованности в трёх пятиэпоховых прогонах. Отдельный причинный эффект каждого параметра эти прогоны не оценивают. Опечатки берутся из датасета, а защищённые участки проверяются по правилам имеющегося генератора. Числа и формулы в исходниках остаются на месте. Токенизатор B, MLM и поиск обучающих отрицательных примеров работают с Train. Оценки учителей для Validation хранятся в отдельном кеше.

Контрастивное обучение использует все известные положительные фрагменты и сравнивает их с отрицательными. Первый диагностический запуск `train_v03.py` ошибочно маскировал отрицательные логиты и не сопоставим с A. Для рабочих прогонов используйте `v03_experiments`. Cross-Encoder оценивает вопрос и фрагмент вместе. Оценки mMARCO кешируются по точным входным текстам и ревизии.

Тесты разделены по предметам. Новый Test в основном состоит из синтетических вопросов и их опечаток. Дополнительно оценивается прежний набор на 295 запросов. Сравнение учитывает как отдельные записи, так и среднее по семействам. Обе проверки используют известные предмет и учебную группу кандидатов, поэтому цифры не описывают открытый поиск среди всех курсов. Проверка близких понятий включает несколько источников, попавших в Train, и нужна как диагностика.

## Артефакты

`ai/generated/v03/` содержит аудит, кандидаты для ручной проверки, таблицы учителей, историю по эпохам, лучшие и последние checkpoints, токенизаторы, `selection.json`, `final-comparison.json`, `test-errors.json` и бенчмарк. FP32, FP16 и INT8, статический браузерный пакет и замеры Chromium сохраняются в `browser-export/`. Кеш браузерного индекса учитывает SHA-256 модели, токенизатора и точного текста каждого фрагмента. Папку `browser-export/embedding-cache/` можно восстанавливать между локальными сборками или в GitHub Actions. Кеши и новые веса остаются за пределами Git.

Для просмотра браузерного пакета можно запустить статическую раздачу каталога:

```bash
python -m http.server -b 127.0.0.1 -d ai/generated/v03/browser-export/browser 8000
```

Демо показывает семантическую выдачу лучшего отдельного энкодера с источниками. Гибрид и Cross-Encoder сравниваются отдельно при оценке.
