# Этап 06 — подготовка датасета

Слабая разметка для retrieval, не генеративные ответы. Существующие вопросы с явным ответом извлекаются из Markdown. Из определений и уникальных содержательных заголовков создаются короткие шаблонные запросы. Ответ — ссылка на неизменённый фрагмент. Сомнительные фрагменты с passage_warning исключаются; document_warning остаётся в метаданных. Это не фактчекинг и не ручная верификация.

```bash
python3 -m ai.indexing.build_index
python3 -m ai.tokenizer.train
python3 -m ai.training.build_dataset
python3 -m unittest discover -s ai/tests -v
```

Формат: ai/generated/dataset/{train,validation,test}-{passages,examples}.jsonl и dataset-manifest.json. Каждое example содержит query, query_kinds, positive_ids (все известные положительные для одного нормализованного вопроса в пределах предмета/набора) и до трёх negative_candidates. Passages хранят оригинальный текст, encoder_text (заголовки + текст), parent_id, источник, строки, хеши, предупреждения. Индекс и токенизатор проверяются по SHA-256.

Сложные отрицательные кандидаты: BM25F в том же предмете, наборе и split; исключаются положительные, тот же файл, одинаковые заголовки, точные дубли и большой лексический overlap. Это потенциальные false negatives, не доказанные неправильные ответы. Этап обучения должен маскировать известные положительные и сомнительные совпадения; не считать все кандидаты гарантированно отрицательными.

Разделение по предметам, а не по случайным парам: validation — mathematical_analysis, test — russian_statehood_fundamentals, train — остальные. Все версии и курсы одного предмета попадают в один split. Удаляются точные нормализованные дубли тела и запроса между split. Такой holdout проверяет перенос на незнакомые предметы, но не является репрезентативной оценкой поиска по всем предметам. Межпредметные смысловые дубли могут сохраниться. BPE уже обучен на всём корпусе (несупервизорная утечка); для строгой независимой оценки потребуется отдельный tokenizer, обученный только на train. Старый ручной BM25 benchmark — smoke, не независимый test.

Контекст 512 с BOS/EOS и заголовками. Длинные блоки делятся только на границах абзацев с сохранением формул и диапазонов строк; неделимые блоки и длинные явные Q&A исключаются, а не обрезаются. Это может исключить часть материала и не гарантирует сохранность всех Markdown-конструкций. Исходный индекс не меняется.

Шаблонные вопросы не заменяют качественные человеческие перефразировки и дистилляцию. На этапе 07 нужно расширить/проверить разметку, оценить качество на независимой выборке, сравнить с BM25F. Не публиковать модель только по факту успешной сборки.
