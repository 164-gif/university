## Проверка информации

Для предмета должна существовать папка `checks/`.
Файл `checks/There might be a mistake.md` используется для возможных ошибок, расхождений и устаревших сведений.

Проверка не должна молча менять основной конспект: исходная запись сохраняется, а замечание выносится отдельно.
