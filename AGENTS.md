# AGENTS.md — правила конспектов и расшифровки

## Главный запрет
Никогда не додумывать неразборчивый текст.

Если фрагмент нельзя уверенно восстановить, использовать:
- [неразборчиво]
- [неразборчиво, 3–5 слов]
- [предположительно: ...] — только если гипотеза действительно полезна и явно помечена
- [формула неразборчива]
- [имя/термин неразборчив]

Запрещено маскировать догадку как точную расшифровку.

## Пайплайн
1. Сохранить исходник без изменений.
2. Сделать максимально дословную расшифровку.
3. Отдельно сделать очищенный конспект.
4. Отдельно сделать краткое резюме.
5. Выделить определения, формулы, даты, имена, термины и вероятные экзаменационные вопросы.
6. Если есть сомнение — сохранить сомнение явно.

## Работа с фото конспектов
- читать страницу целиком, а не отдельные слова вне контекста;
- сохранять порядок страниц;
- не исправлять смысл без уверенности;
- формулы переписывать отдельно;
- если часть формулы не видна — не достраивать её по памяти.

## Формат хорошего конспекта
- тема;
- ключевые понятия;
- основные тезисы;
- определения;
- формулы;
- примеры;
- важные замечания преподавателя;
- что нужно выучить;
- возможные вопросы на зачёт/экзамен.

## Obsidian
Использовать понятные заголовки, списки, wikilinks при необходимости и callout-блоки только когда они реально улучшают навигацию.
